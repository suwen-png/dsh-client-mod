# _memory/_snapshots — 项目记忆快照目录

> 启用日期：2026-09-06（整改 V1.2 任务 #7）

## 工作机制

按 `docs/00-统筹入口/AI规范执行保障机制.md` 第四条（违规纠正流程）：
每次重大变更/L3+任务后，对 _memory/MEMORY.md 做版本快照，便于：
- 追溯决策演变
- 回滚到任意稳定版本
- 跨会话比对记忆差异

## 命名规范

`_memory/_snapshots/MEMORY-YYYYMMDD-HHMM-<tag>.md`

| 段 | 含义 | 示例 |
|:--:|:-----|:-----|
| YYYYMMDD | 快照日期 | 20260906 |
| HHMM | 快照时间（精确到分钟） | 2200 |
| tag | 简短标记（重要决策事件） | v1.2-base / pre-v10-cdp / post-v10-v3 |

## 触发条件

| 触发 | 是否快照 |
|:----|:--------:|
| L3+ 项目任务结束 | ✅ 必须 |
| 项目里程碑（V10 完工/重大修复） | ✅ 必须 |
| 普通文档更新 | ⚠️ 按需 |
| 临时笔记 | ❌ 否 |

## 归档规则

- 每个快照生成时，自动 git commit（不需人为提交）
- 每月将超过 90 天未引用的快照归档到 `_memory/_archive/`
- 跨季度复盘时，提取关键决策蒸馏回 `_memory/MEMORY.md`

## 入口

- 当前主记忆：`_memory/MEMORY.md`
- 历史归档：`_memory/_archive/`
- 本目录索引：本文件
