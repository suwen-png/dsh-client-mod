## 三、思维导图设计要点（设计图见同目录 HTML）

### 3.1 核心语义
- **一个对话 = 一棵树**：根节点=主对话（总监），每个智能体/子方向=一个分支节点
- **点智能体"切换对话"= 从当前节点分叉出一条新分支**（不是覆盖，是派生）
- 分支可再分叉（多级），形成完整探索路径；可合并（结论回收）/删除（废弃路径）

### 3.2 布局
- 横向树（左根右枝），符合"从主线派生"心智；节点纵向均匀分布，曲线连接
- 节点状态色：空闲灰/忙碌橙脉冲/错误红；类型图标：💻代码 📄文档 🔍调研 🧪测试 🤖通用
- 画布支持：滚轮缩放、拖拽平移、一键适应屏幕

### 3.3 两种总监模式回归（都要测）
1. 模式一：原对话页左下角"总监"入口弹出，**不覆盖**原对话
2. 模式二：顶部"总监"tab 覆盖式，右上角 ✕ 关闭回原界面
