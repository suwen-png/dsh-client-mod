# 小窗真实对话流嵌入 — 函数级技术实施方案

## 0. 方案选型说明

**不采用**：从 ChatView 完整提取消息流（含分页锚点、滚动位置恢复、10+ refs、useLayoutEffect 链）。原因：ChatView 该部分逻辑与主区域布局深度耦合，提取风险极高，易破坏现有功能。

**采用**：独立轻量组件 `ChatFlow` / `DirectorFlow`，复制核心渲染逻辑，简化滚动管理。
- 消息交互完整性由 `ChatNodeSeat`（通过 `renderSlot("conversation.chat.node")`）保证，与主区域完全一致
- 简化项：自动滚动到底部（无滚动位置恢复）、加载更多按钮（无分页锚点）、无回到底部按钮
- **零修改** ChatView / DirectorView 现有消息流逻辑，仅替换小窗占位符

## 1. 新增函数清单

### 1.1 ChatFlow 组件（对话消息流，完整交互）

**函数签名**：
```javascript
function ChatFlow({
  sessionId,          // string: 会话ID
  useSession,         // hook: session store hook（slot系统注入）
  useSessions,        // hook: sessions store hook（slot系统注入）
  useStore,           // hook: chatStore hook（slot系统注入）
  renderSlot,         // function: slot渲染函数（slot系统注入）
  t,                  // function: 国际化函数
  openFile,           // function: (path) => void 打开文件
  loadOlder,          // function: () => void 加载更多历史
  loadImage,          // function: (attachment) => Promise<url> 加载图片
  inspectCall,        // function: (callId) => void 查看调用详情
  forkAt,             // function: (seq) => void 分叉会话
  fileMentions,       // function: (owner) => array 文件提及
  compact = false     // boolean: 小窗模式（减小padding/字号）
})
```

**内部数据读取**（与 ChatView 一致，从 useSession/useSessions/useStore 读取）：
```javascript
const order = useSession((s) => s.chat.order);
const nodeStore = useSession((s) => s.chat.nodes);
const timeline = useSession((s) => s.chat.timeline);
const inbox = useSession((s) => s.queue);
const cwd = useSessions((s) => s.byId[sessionId]?.cwd);
const running = useSession((s) => s.running);
const openState = useSession((s) => s.openState);
const openError = useSession((s) => s.openError);
const hasMore = useSession((s) => s.hasMore);
const loadingOlder = useSession((s) => s.loadingOlder);
const selectedCallId = useStore((s) => s.selection?.callId);
const pendingSteering = useMemo(() => inbox.filter(i => i.placement === "steering"), [inbox]);
const runningTurnStart = useMemo(() => runningTurnStartTime(timeline), [timeline]);
```

**内部 refs/state**（简化版，仅3个）：
```javascript
const scrollRef = useRef(null);              // 滚动容器
const lastOrderLen = useRef(order.length);   // 上次消息数，用于判断新消息
```

**内部 effects**：
```javascript
// 新消息自动滚动到底部
useEffect(() => {
  if (order.length > lastOrderLen.current && scrollRef.current) {
    scrollRef.current.scrollTop = scrollRef.current.scrollHeight;
  }
  lastOrderLen.current = order.length;
}, [order.length, running]);
```

**渲染结构**（JSX）：
```javascript
<div ref={scrollRef} style={{ flex:1, overflowY:"auto", padding: compact?8:16 }}>
  {/* loading提示 */}
  {openState === "loading" && <div>{t("chat.loadingHistory")}</div>}
  {/* error提示 */}
  {openState === "error" && openError && <div>{t("chat.loadError", {...})}</div>}
  {/* 加载更多按钮 */}
  {hasMore && <button onClick={loadOlder} disabled={loadingOlder}>
    {loadingOlder ? t("loading") : t("chat.loadOlder")}
  </button>}
  {/* 消息列表 — ChatNodeSeat提供完整交互 */}
  {order.map((nodeKey) => (
    <ChatNodeSeat
      key={nodeKey}
      nodeKey={nodeKey}
      useSession={useSession}
      selectedCallId={selectedCallId}
      cwd={cwd}
      openFile={openFile}
      inspectCall={inspectCall}
      forkAt={forkAt}
      loadImage={loadImage}
      fileMentions={fileMentions}
      renderSlot={renderSlot}
      t={t}
    />
  ))}
  {/* 运行状态指示器 */}
  {running && <TurnStatus startTime={runningTurnStart} t={t} />}
  {/* 待处理转向气泡 */}
  {pendingSteering.map((item) => (
    <PendingSteeringBubble key={item.id} content={item.content} loadImage={loadImage} t={t} />
  ))}
</div>
```

**依赖的现有组件**（无需修改，直接复用）：
- `ChatNodeSeat`（行5281，memo组件）— 消息节点渲染，完整交互
- `TurnStatus`（行~5380）— 运行状态指示器
- `PendingSteeringBubble`（行~5100）— 待处理转向气泡
- `runningTurnStartTime`（工具函数）— 计算运行开始时间

### 1.2 DirectorFlow 组件（总监消息流，完整交互）

**函数签名**：
```javascript
function DirectorFlow({
  sessionId,              // string: 会话ID
  onConfirmSend = null,   // function: (instruction) => void 确认发送回调（小窗中调用window.__directChatSubmit）
  compact = false         // boolean: 小窗模式
})
```

**内部数据读取**：
```javascript
const store = directorStoreFactory(sessionId);   // 获取/创建总监store（按sessionId共享）
const state = useDirectorStore(store);           // 订阅store变化
const messagesEndRef = useRef(null);             // 滚动到底部锚点
```

**内部 effects**：
```javascript
// 新消息自动滚动到底部
useEffect(() => {
  messagesEndRef.current?.scrollIntoView({ behavior: "smooth" });
}, [state.messages.length, state.status]);
```

**渲染结构**（复用 DirectorView 行7152-7173 的消息气泡逻辑）：
```javascript
<div ref={messagesEndRef} style={{ flex:1, overflowY:"auto", padding: compact?8:16, display:"flex", flexDirection:"column", gap: compact?8:12 }}>
  {state.messages.length === 0 ? (
    <div style={{ color:"#999", fontSize: compact?11:13, textAlign:"center", marginTop:40 }}>
      总监对话流为空，输入消息开始
    </div>
  ) : state.messages.map((msg) => (
    <div key={msg.id} style={{
      alignSelf: msg.role === "user" ? "flex-end" : "flex-start",
      maxWidth: compact?"90%":"80%",
      padding: compact?"6px 10px":"8px 12px",
      borderRadius: 8,
      background: msg.role === "user" ? "#e3f2fd" : msg.role === "system" ? "#fff3cd" : "#f5f5f5",
      fontSize: compact?12:13,
      lineHeight: 1.5,
      whiteSpace: "pre-wrap",
      wordBreak: "break-word"
    }}>
      {/* parsed信息卡片 */}
      {msg.role === "assistant" && msg.parsed && (
        <div style={{ marginBottom:8, padding:"6px 8px", background:"#fff", borderRadius:4, border:"1px solid #eee", fontSize: compact?10:11 }}>
          <div>整理后指令: {msg.parsed.instruction}</div>
          {msg.parsed.model && <div>模型建议: {msg.parsed.model}</div>}
          {msg.parsed.branch && <div>分支建议: {msg.parsed.branch}</div>}
        </div>
      )}
      {/* 消息内容 */}
      <div>{msg.content}</div>
      {/* 确认发送按钮（autoForward关闭时） */}
      {msg.role === "assistant" && msg.parsed && !state.config.autoForward && onConfirmSend && (
        <button onClick={() => onConfirmSend(msg.parsed.instruction)} style={{
          marginTop:8, padding:"4px 12px", fontSize: compact?11:12,
          background:"#1976d2", color:"#fff", border:"none", borderRadius:4, cursor:"pointer"
        }}>
          确认发送
        </button>
      )}
    </div>
  ))}
  {/* 处理中指示器 */}
  {state.status === "processing" && (
    <div style={{ alignSelf:"flex-start", padding:"4px 10px", background:"#fff3cd", borderRadius:4, fontSize: compact?11:12 }}>
      总监处理中...
    </div>
  )}
</div>
```

**依赖的现有函数**（无需修改）：
- `directorStoreFactory(sessionId)`（行5449）— 获取/创建总监store
- `useDirectorStore(store)`（行5455）— React hook订阅store变化

### 2.1 修改：总监tab的 inject 函数（行~10190）

**当前返回**：`{ setView, sendToChat, loadOlder, loadImage }`

**修改后返回**（新增 ChatFlow 需要的 props）：
```javascript
inject: (sessionId, actions) => {
  const conversation = concreteConversation(ctx);
  const scoped = scopedConversation(sessions, sessionId);
  return {
    // 已有
    setView: (view) => actions.setView(view),
    sendToChat: (text) => { ... },
    loadOlder: () => scoped.loadOlder(),
    loadImage: (attachment) => conversation.resolveImage(sessionId, attachment),
    // 新增 — ChatFlow 需要的 props
    openFile: (path) => {
      const cwd = sessions.list.getSnapshot().byId[sessionId]?.cwd;
      workspaces.openPath(resolveWorkspacePath(cwd, path)).catch(() => {});
    },
    inspectCall: (callId) => {
      actions.select({ callId });
      actions.setView("trajectory");
    },
    forkAt: (seq) => {
      sessions.fork({ sessionId, atSeq: seq, increaseTitle: true })
        .then((childId) => sessions.open(childId)).catch(() => {});
    },
    fileMentions: (owner) => ctx.get("chatFileMentions")?.forClosing(owner),
    chatScroll: {
      save: () => {},  // 小窗中简化，不保存滚动位置
      read: () => null
    }
  };
}
```

## 4. 数据流与调用链

### 4.1 总监tab → 右侧对话小窗
```
用户点击总监tab
  → DirectorView 挂载
    → useEffect 设置 window.__directorCurrentView="director", focusTarget="director"
    → 右侧小窗渲染 <ChatFlow sessionId=... compact=true />
      → ChatFlow.useSession 读取同一会话的 order/nodes
      → order.map → ChatNodeSeat → renderSlot 渲染消息（完整交互）
      → 新消息自动滚动到底部
用户点击右侧对话小窗
  → onClick → directorLayoutStore.setFocusTarget("chat")
    → window.__directorFocusTarget = "chat"
用户在输入框输入消息并发送
  → InputBar.keyboard.submit / inputActions.submit
    → 读取 window.__directorCurrentView="director", focusTarget="chat"
    → 调用 window.__directChatSubmit(sessionId, draft)
      → conversation.sendSession(sess, draft, [], "chat")
        → 消息出现在对话历史中
          → ChatFlow（小窗）和 ChatView（主区域）同时通过 useSession 看到新消息
```

### 4.2 对话tab → 左侧总监小窗
```
用户点击对话tab
  → ChatView 挂载
    → useEffect 设置 window.__directorCurrentView="chat", focusTarget="chat"
    → 左侧小窗渲染 <DirectorFlow sessionId=... compact=true />
      → DirectorFlow.directorStoreFactory(sessionId) 获取同一总监store
      → useDirectorStore 订阅消息变化
      → 渲染总监消息气泡（含parsed信息、确认发送按钮）
用户点击左侧总监小窗
  → onClick → directorLayoutStore.setFocusTarget("director")
    → window.__directorFocusTarget = "director"
用户在输入框输入消息并发送
  → InputBar 读取 currentView="chat", focusTarget="director"
    → 调用 window.__directorSubmit(sessionId, draft)
      → directorProcessMock → store.addMessage → 总监消息出现在总监流中
        → DirectorFlow（小窗）和 DirectorView（主区域）同时看到新总监消息
      → autoForward=true 时自动 onForward(instruction)
        → conversation.sendSession → 对话消息出现在对话流中
```

## 5. 风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|---------|
| ChatFlow 缺少 ChatView 的分页锚点逻辑，加载更多后滚动位置不对 | 中 | 小窗中加载更多历史后可能跳到顶部 | 小窗中简化处理：加载更多后不恢复位置，用户手动滚动。主区域 ChatView 不受影响 |
| DirectorView inject 新增 props 后，slot 系统注入冲突 | 低 | 总监tab可能渲染异常 | 新增 props 名称与 ChatView inject 一致，slot 系统按名称注入，不会冲突 |
| ChatNodeSeat 在小窗中因宽度不足导致布局错乱 | 中 | 消息气泡可能溢出 | compact 模式下消息气泡 maxWidth 设为 90%，字号减小 |
| 小窗中 ChatFlow 和主区域 ChatView 同时渲染，性能开销 | 低 | 消息量大时可能卡顿 | 两个组件共享同一 useSession 数据，React 会批量更新；小窗只在总监tab可见时渲染 |
| DirectorFlow 的确认发送按钮在小窗中点击后，消息发送目标不对 | 低 | 确认发送可能发到错误目标 | onConfirmSend 明确调用 window.__directChatSubmit，直接发对话，不经过焦点判断 |
