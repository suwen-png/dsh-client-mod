## 二、根因分析（步骤4输入）

### 2.1 历史教训：前九次修改改错了地方

**问题**：V1-V4给a-1/a-2添加的滚动逻辑操作的是内部容器`messagesEndRef`/`scrollRef`（`overflowY:auto`）。

**为什么无效**：在`data-phase=active`时，CSS规则`viewArea { flex: 1 0 auto; min-height: auto }`让viewArea高度由内容决定。此时内部容器高度=内容高度，**内部容器不产生滚动条**，实际滚动条出现在父级`scrollBody`（`[data-conversation-scroll]`，`overflow: hidden auto`）。操作一个不滚动的容器的`scrollTop`等于什么都没做。

**正确做法**：和b2（ChatView源客户端标准对话）一致——用`el.closest("[data-conversation-scroll]")`找到scrollBody，操作它的scrollTop，监听它的scroll事件。

**V5第十次修改才改对地方**，本次V6确认并完善。

### 2.2 A1总监消息不持久化的根因

**代码位置**：`directorStoreFactory(sessionId)`（原行5507）

**根因**：`directorStores` Map用原始`sessionId`作key。如果`sessionId`是对象引用（非原始值），每次React渲染可能传入不同的对象引用（即使值相同），`Map.has()`返回false，导致**每次渲染都创建新store**，旧store的消息丢失。

**修复**：Map key改用`safeDirectorKey(sessionId)`字符串结果（`String(sessionId).replace(/[^a-zA-Z0-9_-]/g, "_")`），确保值相同的sessionId返回同一个store。

### 2.3 发送消息后不滚底的根因

**a-1 DirectorView**：useLayoutEffect中有`if (dvAtBottomRef.current)`守卫。用户上滑后`atBottomRef=false`，发送消息后不满足守卫条件，不滚底。

**修复**：添加判断——最后一条消息`role === "user"`时，**无条件滚底**（不管atBottomRef）。因为发送消息是用户主动行为，用户期望看到自己发的消息。

**a-2 ChatFlow**：同上，useEffect中有`if (cfAtBottomRef.current)`守卫。修复方式相同——最后一个节点`kind === "user"`时无条件滚底。

**b-1 ChatView**：源客户端逻辑中`appendedUser`（`lastKey !== lastKeyRef.current && lastNode?.kind === "user"`）已无条件toBottom，理论上正常。如仍有问题需运行时确认。

### 2.4 A2无法对话的根因

**机制确认**：A2发送链路完整——
1. 点击A2区域 → `directorLayoutStore.setFocusTarget("chat")`
2. 全局输入框提交 → 检测`dirView==="director" && focusTarget==="chat"` → 调用`window.__directChatSubmit(sessionId, draft)`
3. `__directChatSubmit` → `conversation.sendSession(session, draft, [], "queue")` → 发送到实际会话
4. A2（ChatFlow）订阅同一session → 显示消息

**问题**：用户可能不知道需要先点击A2区域。已添加header视觉提示（绿色"✓ 输入发送到此"）。

### 2.5 页面log标签

**问题**：DirectorView状态栏有15个probe徽章（view/gView/submit/setView/focus/sid/dMsg/useSess/useStore/direct/scroll/directCall/lastSend/persist），全部fontSize:10。

**修复**：统一给fontSize:10的style添加`display: "none"`。状态标签（fontSize:11，如"总监处理完成"）保留。

## 三、修改清单（步骤8落地执行记录）

### 修改文件
`workspace/@deepseek-ai/dsh-client-ui-conversation/lib/client.js`

### 修改1：持久化——directorStores Map key改用字符串

**位置**：`directorStoreFactory`函数

**修改前**：
```js
function directorStoreFactory(sessionId) {
    if (!directorStores.has(sessionId)) {
        directorStores.set(sessionId, createDirectorStore(sessionId));
    }
    return directorStores.get(sessionId);
}
```

**修改后**：
```js
function directorStoreFactory(sessionId) {
    const mapKey = safeDirectorKey(sessionId);
    if (!directorStores.has(mapKey)) {
        if (typeof window !== "undefined" && window.__dshDebug)
            window.__dshDebug.log("persist", "directorStoreFactory: create new store for key=" + mapKey + " (sessionId type=" + typeof sessionId + ")");
        directorStores.set(mapKey, createDirectorStore(sessionId));
    }
    return directorStores.get(mapKey);
}
```

## 八、A2发送消息操作说明（用户参考）

A2遵循「全局单输入框」设计，无独立输入框。发送方式：
1. **点击A2区域任意位置** → A2边框变蓝 + header变绿显示「✓ 输入发送到此」
2. 在**底部全局输入框**输入消息并提交
3. 消息直接发送到A2对应的实际会话，A2实时显示

如点击A2后header没变绿，说明focusTarget未切换，需排查。
