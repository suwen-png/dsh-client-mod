## 二、修改内容

### D-01 主题变量体系
- 新增 `dshThemeStore`（getTheme/setTheme/reset/subscribe），localStorage `dsh-v9-theme` 持久化，X9 降级（try/catch 仅会话级）
- `dshApplyThemeVars()` 注入 `:root` CSS 变量：`--dsh-ac / --dsh-ac-soft / --dsh-ac2 / --dsh-mem / --dsh-density`
- 设置弹层新增「外观」区块：主强调色 4 色（蓝#4d6bfe/青#14b8a6/紫#8b5cf6/橙#f59e0b）+ 记忆高亮 3 色 + 密度 2 档 + 恢复默认
- **范围控制**：本批次 accent 变量先行（R1/智能体/焦点框等强调元素引用 `var(--dsh-ac, #1976d2)`，fallback=现有色，未设置时视觉零变化）；面板背景全量暗色令牌迁移留批次3（D-06 重样式），避免半成品混搭

### D-02 布局骨架对齐
- 删除红色调试边框（`border: 3px solid #d32f2f`）和 `DIRECTOR-V5-LOADED` badge
- R1 顶栏：项目名 chip（超长省略号+title）/ 阶段 chip / 驾驶舱 accent chip / 右侧：切换项目 ghost（点击 Toast「V10 实现」）+ ⚙ 设置
- R2 总览占位条：可折叠（useState r2Collapsed，默认折叠），内容区显示「总览卡片 · 批次2 填充」
- a-2 边缘条：28px 竖排文字「a-2 · 点击展开」，点击恢复
- 断点（ResizeObserver 监听根 div，记录上次宽度，**仅下穿阈值时自动折叠**，不与用户展开操作打架）：
  - <880px：a-2 自动折叠为 rail
  - <640px：R4（上面框）+ R6（下面框）自动折叠
- 保留现有：R4 项目文件（折叠+拖拽 ✓）、R6 总监文档（hover展开+锁定+拖拽 ✓）、对话区、焦点路由、设置弹层原功能

### D-03 docs-index 生成与注入
- `gen-docs-index.ps1`：扫描 `docs/**/*.md` → 构建 `{generatedAt, version, docCount, tree, docs}`（每文档截断 8000 字符）→ 正则替换 workspace client.js 标记间内容为 `const DSH_DOCS_INDEX = {...}` → 无 BOM 写回
- apply.ps1 在加载库后、快照前调用生成脚本（保证快照与施加内容一致）
- client.js 运行时：`window.__dshDocsIndex = DSH_DOCS_INDEX`（标记默认 null = X3 降级态，D-04/D-05 读取时判空）

## 四、回滚方案

- 一键回滚：`.\restore.ps1`（original/ 复原 client.js；apply.ps1 为脚本新增，git 外文件，手动还原或保留无害）
- 快照回滚：`snapshots/before-apply-*` 恢复 workspace
- docs-index 标记默认 null，即使 gen 失败也不会导致 client.js 运行错误（X3 降级）

## 五、风险与缓解

| 风险 | 缓解 |
|------|------|
| ResizeObserver 自动折叠与用户操作打架 | 仅下穿阈值触发一次（记录上次宽度），不自动展开 |
| gen 注入 JSON 含特殊字符破坏 JS | ConvertTo-Json 转义 + 注入后 node --check 双重验证 |
| 每次 apply client.js 必变（generatedAt 时间戳） | 可接受（本项目 client.js 本就持续修改）；快照照旧 |
| 断点宽度基于根 div（插件区），符合设计 | 根 div 即对话面主区，与附录F一致 |
