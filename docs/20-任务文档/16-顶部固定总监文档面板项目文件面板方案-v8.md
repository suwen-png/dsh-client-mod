## 三、方案设计

### 3.1 整体布局（V8）

```
DirectorView (flex column, height:100%)
├── 顶部固定栏 (flexShrink:0)
│   ├── 状态栏：总监待命 + 自动转发 + 导出日志 + 滚到底 + ⚙设置
│   └── 智能体/技能/执行逻辑 行（待实现→改为项目文件面板入口）
├── 上面框：项目文件面板 (可伸缩, flexShrink:0)
│   ├── 标题栏：项目文件 + 折叠/展开按钮
│   └── 文件列表（当前session/cwd下的文件）
├── 对话历史区 (flex:1, overflowY:auto) ← 唯一滚动容器
│   └── 消息列表
├── 中间拖拽条 (flexShrink:0)
└── 下面框：总监文档面板 (可伸缩, flexShrink:0)
    ├── 标题栏：总监文档 + 折叠/展开按钮 + 新建文档
    └── 文档列表（按三类分组：核心记忆/需求索引/业务数据）
```

### 3.2 a-2 双模式切换

```
a-2 (右侧小窗)
├── 对话模式（默认）：ChatFlow 标准对话
└── 文档编辑模式（点击文件/文档时触发）：
    ├── 标题栏：文档名 + 类型标签
    ├── 内容编辑区：textarea 或 contenteditable
    └── 底部按钮：保存 / 取消
```

- 点击保存 → 持久化到IndexedDB/文件系统 → 切换回对话模式
- 点击取消 → 不保存 → 切换回对话模式
- 对话模式用 `display:none` 隐藏而非卸载，保留ChatFlow状态

### 3.3 数据层设计

#### 3.3.1 总监文档（IndexedDB）
- 数据库：`dsh-director-db`（已有）
- 新增store：`directorDocs`，keyPath: `docId`
- 文档结构：
  ```js
  {
    docId: "doc-xxx",
    docName: "文档名",
    docType: "core_memory" | "requirement_index" | "business_data",
    folderId: "folder-xxx" | null,
    content: "Markdown内容",
    tags: [],
    createdAt: timestamp,
    updatedAt: timestamp
  }
  ```
- 文件夹结构：
  ```js
  {
    folderId: "folder-xxx",
    folderName: "文件夹名",
    docType: "core_memory" | ...,
    createdAt: timestamp
  }
  ```

#### 3.3.2 项目文件
- 通过原客户端 `useSessions` 获取当前session的cwd
- 读取cwd下的文件列表（通过Electron fs或原客户端API）
- 文件内容读取/写入通过原客户端 `openFile` 或Electron fs

### 3.4 交互流程

#### R2 总监文档流程
1. 用户展开底部总监文档面板
2. 面板展示三类文档分组（核心记忆/需求索引/业务数据），每组下有文件夹和文档
3. 用户点击某文档
4. a-2从对话模式切换为文档编辑模式，加载该文档内容
5. 用户编辑内容
6. 用户点击"保存"→ 写入IndexedDB → a-2恢复对话模式
7. 用户点击"取消"→ 不保存 → a-2恢复对话模式

#### R3 项目文件流程
1. 用户展开顶部项目文件面板
2. 面板展示当前项目（cwd）下的文件列表
3. 用户点击某文件
4. a-2从对话模式切换为文件编辑模式，加载该文件内容
5. 用户编辑内容
6. 用户点击"保存"→ 写入文件系统 → a-2恢复对话模式
7. 用户点击"取消"→ 不保存 → a-2恢复对话模式
