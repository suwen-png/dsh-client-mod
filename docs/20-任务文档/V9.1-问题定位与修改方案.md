## 〇、根因确认与修改执行记录（2026-08-27）

### 固定失败 — 真正根因（已确认）

**布局链**：
```
ConversationRoot (root, height:100%, flex column)
├── header (flex:none)
├── scrollBody (flex:1, overflow:hidden auto) ← 这是滚动容器！
│   └── conversation.session slot
│       └── ConversationSession
│           └── viewArea (flex:1, min-height:0)
│               └── conversation.view slot (DirectorView/ChatView)
│                   └── DirectorView根容器 (height:100%, overflow:hidden)
└── composerSeat (flex:none, position:sticky bottom:0)
```

**关键CSS规则**（第8048行）：
```css
.RWZidW_scrollBody { overflow: hidden auto; }  /* scrollBody是滚动容器 */
.RWZidW_root[data-phase=active] .RWZidW_viewArea {
    flex: 1 0 auto;  /* 高度由内容撑开！ */
    min-height: auto;
}
```

**根因**：当对话处于active阶段时，CSS规则让viewArea的高度由内容撑开（`flex:1 0 auto`），而不是占满scrollBody的可视高度。导致scrollBody滚动时，整个viewArea（包括DirectorView的蓝色栏）跟着滚动。DirectorView的`height:100%`是相对于viewArea的，而viewArea高度由内容撑开，所以DirectorView高度也是内容高度，不固定。

**修改**（第9016行，ConversationSession的viewArea渲染）：
```javascript
// 增加inline style覆盖CSS规则
style: { height: "100%", flex: "1 1 0", minHeight: 0, overflow: "hidden", display: "flex", flexDirection: "column" }
```

if (dirView === "director") {

## 二、问题1：总监对话持久化不生效

### 2.1 现象
- 在总监页发送消息后，完全退出软件再重新打开，总监消息全部消失
- 日志显示：`load: no data for key=dsh.director.store.session-9f45bde3-...`

### 2.2 代码定位

| 项目 | 位置 |
|------|------|
| 文件 | `workspace/@deepseek-ai/dsh-client-ui-conversation/lib/client.js` |
| 函数 | `safeDirectorKey(sessionId)` |
| 原行号 | 约5896行 |
| 调用方 | `loadDirectorStore()`、`saveDirectorStore()`、`createDirectorStore()`、`hydrate()` |

### 2.3 原实现
```javascript
function safeDirectorKey(sessionId) {
    return String(sessionId || "unknown").replace(/[^a-zA-Z0-9_-]/g, "_");
}
```

### 2.4 根因分析
- `sessionId` 是 Harness 客户端生成的 UUID（如 `session-9f45bde3-209e-40b5-a17c-d8d78b602ccd`）
- **每次启动软件都会生成新的 sessionId**
- 持久化 key = `dsh.director.store.${safeDirectorKey(sessionId)}` = `dsh.director.store.session-9f45bde3-...`
- 因为每次启动 sessionId 不同，所以 key 不同，永远加载不到之前保存的数据
- 数据确实保存了，但保存在了上次启动的那个 key 下，新启动用新 key 加载，所以"没有数据"

### 2.5 修改方案
- 总监是**全局大总监**，负责主记忆，不应该随会话变化
- 使用**固定 key** `"director-main"` 持久化，不随 sessionId 变化
- 未来支持多项目时，可按项目名称生成 key，但当前全局总监使用固定 key

### 2.6 修改内容
```javascript
function safeDirectorKey(sessionId) {
    // V9.1修复: 总监是全局大总监，使用固定key持久化
    // 原实现使用sessionId(UUID)，每次启动都不同，导致持久化完全失效
    return "director-main";
}
```

### 2.7 验证方法
1. 清除缓存后重启
2. 在总监页发送2-3条消息
3. 完全退出 Harness（任务管理器确认进程退出）
4. 重新打开 Harness，进入总监页
5. 确认之前发送的消息还在
6. 查看日志：应该显示 `load: key=dsh.director.store.director-main msgs=N`

## 三、问题2：蓝色顶部栏不固定

### 3.1 现象
- a-1和b-1顶部有蓝色栏，但滚动对话时蓝色栏会跟着滚动，或者布局上不固定
- 用户要求：**一直固定**，不是滚动时sticky固定，而是布局上永远在顶部，不随任何滚动移动

### 3.2 代码定位

#### a-1蓝色栏
| 项目 | 位置 |
|------|------|
| 文件 | `workspace/@deepseek-ai/dsh-client-ui-conversation/lib/client.js` |
| 组件 | `DirectorView`（a-1） |
| 函数定义行 | 约8214行 `function DirectorView(...)` |
| return开始行 | 约8448行 |
| 蓝色栏位置 | return children 第2个元素（DIRECTOR-V5-LOADED标签之后） |

#### b-1蓝色栏
| 项目 | 位置 |
|------|------|
| 文件 | `workspace/@deepseek-ai/dsh-client-ui-conversation/lib/client.js` |
| 组件 | `ChatView`（b-1主对话区） |
| 函数定义行 | 约6370行 |
| return开始行 | 约6595行 |
| 蓝色栏位置 | b-1主对话区div的children第1个元素 |

### 3.3 a-1布局结构（当前）
```
DirectorView根容器 (flex column, height:100%, overflow:hidden)
├── DIRECTOR-V5-LOADED标签 (position:absolute)
├── 蓝色栏 (flexShrink:0) ← 应该固定
├── 状态栏 (flexShrink:0) ← 应该固定
├── 智能体三栏 (flexShrink:0) ← 应该固定
├── 中间区域 (flex:1, minHeight:0, flex row)
│   ├── 左侧区域 (flex:1, flex column)
│   │   ├── 项目文件面板 (height:topPanelHeight, flexShrink:0)
│   │   ├── 上拖拽条 (height:5, flexShrink:0)
│   │   ├── 对话历史区 (flex:1, overflowY:auto) ← 唯一应该滚动的容器
│   │   ├── 下拖拽条 (height:5, flexShrink:0)
│   │   └── 总监文档面板 (height:bottomPanelHeight, flexShrink:0)
│   └── a-2小窗对话 (width:chatPanelWidth, flexShrink:0)
```

### 3.4 根因分析
- 从布局结构看，蓝色栏在根容器中，根容器是 `overflow:hidden`，蓝色栏是 `flexShrink:0`，理论上应该一直固定
- 之前错误地添加了 `position:sticky`，这可能导致布局异常
- **sticky是滚动时固定，不是一直固定**。sticky元素在滚动容器内，滚动到顶部时才固定。用户要的是布局上永远固定，不应该用sticky
- 可能的真正问题：根容器的 `height:100%` 没有生效，导致根容器高度由内容撑开，整个根容器可以滚动，蓝色栏跟着滚动

### 3.5 修改方案
1. **移除 `position:sticky`**，sticky不适合"一直固定"的需求
2. **确保根容器高度固定**：`height:100%` + `overflow:hidden` + `min-height:0`
3. **确保唯一滚动容器是对话历史区**：只有对话历史区设置 `overflowY:auto`，其他区域都不设置overflow
4. **蓝色栏、状态栏、智能体三栏都保持 `flexShrink:0`**，不设置任何position，靠flex布局固定

### 3.6 修改内容
#### a-1蓝色栏
```javascript

// 只保留 flexShrink:0，靠flex布局固定

    style: {
        display: "flex",
        justifyContent: "space-between",
        alignItems: "center",
        padding: "6px 16px",
        background: "linear-gradient(135deg, #1565c0, #1976d2)",
        color: "#fff",
        flexShrink: 0,  // 靠这个固定，不需要sticky
        borderBottom: "1px solid #0d47a1"
    },
    children: [...]

```

#### a-1根容器
```javascript

    display: "flex",
    flexDirection: "column",
    height: "100%",
    overflow: "hidden",  // 关键：根容器不滚动
    position: "relative"
}
```

#### b-1蓝色栏
同样移除 `position:sticky`，只保留 `flexShrink:0`。

## 四、问题3：a-1上下伸缩不好用

### 4.1 现象
- a-1左侧有上下两个可拖拽调节高度的面板：
  - 上面框：项目文件面板（可拖拽下边缘调节高度）
  - 下面框：总监文档面板（可拖拽上边缘调节高度）
- 拖拽调节高度不好用，可能拖不动、跳动、或不响应

### 4.2 代码定位

| 项目 | 位置 |
|------|------|
| 文件 | `workspace/@deepseek-ai/dsh-client-ui-conversation/lib/client.js` |
| 组件 | `DirectorView`（a-1） |
| 上面框state | `topPanelHeight`（默认140）、`topPanelCollapsed` |
| 上面框拖拽函数 | `onTopResizerMouseDown`（约8358行） |
| 下面框state | `layout.bottomPanelHeight`（默认180）、`layout.bottomPanelCollapsed` |
| 下面框拖拽函数 | `onBottomResizerMouseDown`（约8412行） |
| 上面框拖拽条 | 项目文件面板之后，对话历史区之前（约8546行） |
| 下面框拖拽条 | 对话历史区之后，总监文档面板之前（约8594行） |

### 4.3 原实现分析

#### 上面框拖拽
```javascript
const [topPanelHeight, setTopPanelHeight] = useState(140);
const onTopResizerMouseDown = useCallback((e) => {
    e.preventDefault();
    e.stopPropagation();
    isDraggingTop.current = true;
    const startY = e.clientY;
    const startH = topPanelHeight;
    const onMove = (ev) => {
        if (!isDraggingTop.current) return;
        setTopPanelHeight(Math.max(60, Math.min(300, startH + (ev.clientY - startY))));
    };
    const onUp = () => {
        isDraggingTop.current = false;
        document.removeEventListener("mousemove", onMove);
        document.removeEventListener("mouseup", onUp);
    };
    document.addEventListener("mousemove", onMove);
    document.addEventListener("mouseup", onUp);
}, [topPanelHeight]);
```

#### 下面框拖拽
```javascript
const onBottomResizerMouseDown = useCallback((e) => {
    e.preventDefault();
    e.stopPropagation();
    isDraggingBottom.current = true;
    const startY = e.clientY;
    const startHeight = layout.bottomPanelHeight;
    const onMove = (ev) => {
        if (!isDraggingBottom.current) return;
        // 向上拖增加高度，向下拖减少高度
        directorLayoutStore.setBottomPanelHeight(startHeight + (startY - ev.clientY));
    };
    ...
}, [layout.bottomPanelHeight]);
```

### 4.4 可能的问题
1. **拖拽条高度太小**（5px），不容易精准点击到
2. **拖拽条没有z-index**，可能被其他元素遮挡
3. **上面框拖拽方向反了**：向下拖应该增加高度，但代码是 `startH + (ev.clientY - startY)`，向下拖ev.clientY增大，高度增加，这是对的
4. **下面框拖拽方向**：向上拖增加高度，代码是 `startHeight + (startY - ev.clientY)`，向上拖ev.clientY减小，高度增加，这是对的
5. **useCallback依赖问题**：上面框依赖`topPanelHeight`，每次高度变化都会重新创建函数，可能导致事件监听重复
6. **拖拽时文本选中**：虽然preventDefault了，但可能还需要user-select:none
7. **下面框使用全局store**：`directorLayoutStore.setBottomPanelHeight`，可能有异步更新问题

### 4.5 修改方案
1. **增大拖拽条可点击区域**：高度从5px增加到8px，增加上下各2px的透明padding
2. **增加cursor:row-resize** 和 `user-select:none`
3. **增加z-index**，确保拖拽条在最上层
4. **修复useCallback依赖**：使用ref保存当前高度，不依赖state，避免重复创建函数
5. **增加拖拽时的视觉反馈**：拖拽时改变拖拽条背景色
6. **确保拖拽条不被对话历史区的滚动遮挡**

### 4.6 修改内容
#### 拖拽条样式
```javascript
// 上面框拖拽条
style: {
    height: 8,  // 从5px增加到8px
    background: "#e0e0e0",
    cursor: "row-resize",
    flexShrink: 0,
    borderTop: "1px solid #ccc",
    borderBottom: "1px solid #ccc",
    position: "relative",
    zIndex: 10,  // 确保在最上层
    userSelect: "none"
}
```

#### 拖拽函数优化（使用ref避免重复创建）
```javascript
const topPanelHeightRef = useRef(topPanelHeight);
useEffect(() => { topPanelHeightRef.current = topPanelHeight; }, [topPanelHeight]);

const onTopResizerMouseDown = useCallback((e) => {
    e.preventDefault();
    e.stopPropagation();
    isDraggingTop.current = true;
    const startY = e.clientY;
    const startH = topPanelHeightRef.current;  // 使用ref
    const onMove = (ev) => {
        if (!isDraggingTop.current) return;
        setTopPanelHeight(Math.max(60, Math.min(300, startH + (ev.clientY - startY))));
    };
    const onUp = () => {
        isDraggingTop.current = false;
        document.removeEventListener("mousemove", onMove);
        document.removeEventListener("mouseup", onUp);
    };
    document.addEventListener("mousemove", onMove);
    document.addEventListener("mouseup", onUp);
}, []);  // 空依赖，函数只创建一次
```
