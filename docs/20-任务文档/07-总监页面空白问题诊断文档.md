# 总监页面空白问题诊断文档

## 问题现象
- 总监tab页面完全空白，标题栏调试标签（sid/dMsg等）均不可见
- 对话页面正常
- 页面无显式报错信息

## 根因分析

### 假设1：ChatFlow 组件中 useSession 为 undefined（高概率）
**原因**：
- DirectorView 内部从未使用 `useSession`（只用 useDirectorStore），无法确认 slot 系统是否在总监tab注入了 useSession
- ChatFlow 中直接调用 `useSession((s) => s.chat.order)`，无保护
- 如果 useSession 为 undefined，抛出 `TypeError: useSession is not a function`，导致整个 DirectorView 崩溃
- React 错误边界捕获后显示空白

**验证方法**：在 ChatFlow 中添加 useSession 保护，为 undefined 时显示错误信息

### 假设2：ChatFlow 组件中 useStore 为 undefined（中概率）
**原因**：
- DirectorView 中使用了 `useStore ? useStore(...) : "unknown"`（有保护），暗示 useStore 可能为 undefined
- ChatFlow 中直接调用 `useStore((s) => s.selection?.callId)`，无保护
- 如果 useStore 为 undefined，同样导致崩溃

**验证方法**：在 ChatFlow 中添加 useStore 保护

### 假设3：TurnStatus / PendingSteeringBubble / runningTurnStartTime 未定义（低概率）
**原因**：这些组件/函数在 ChatFlow 之前定义，应该可用
**验证方法**：检查定义位置

### 假设4：总监tab inject 新增 props 执行时抛错（低概率）
**原因**：openFile 中引用了 workspaces / _deepseek_ai_dsh_client_runtime_client，可能在作用域中不可用
**验证方法**：ChatView inject 中使用了相同变量且正常，排除此可能

## 诊断结论
最可能根因：**假设1 + 假设2** — ChatFlow 中 useSession/useStore 无保护，在总监tab中为 undefined 时导致组件崩溃。

## 修复方案
在 ChatFlow 组件中：
1. 添加 useSession 保护：`if (!useSession) return <div>useSession unavailable</div>`
2. 添加 useStore 保护：`const selectedCallId = useStore ? useStore(...) : null`
3. 保留 try-catch 错误显示

## 审核清单
- [ ] ChatFlow 中 useSession 有保护，为 undefined 时不崩溃
- [ ] ChatFlow 中 useStore 有保护，为 undefined 时不崩溃
- [ ] 修复后总监页面标题栏可见（含调试标签）
- [ ] 修复后总监主区域消息流正常渲染
- [ ] 修复后右侧对话小窗显示对话历史或明确的不可用提示
- [ ] 对话页面不受影响
