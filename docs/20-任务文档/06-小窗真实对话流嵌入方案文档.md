# 小窗真实对话流嵌入方案文档（完整版）

## 1. 需求理解

### 1.1 核心诉求
- **总监tab右侧对话小窗**：显示真实对话历史，与对话tab主区域同一会话，**消息具备完整交互**（点击查看详情、代码块复制、工具调用展开/折叠、加载更多历史等）
- **对话tab左侧总监小窗**：显示真实总监对话历史，与总监tab主区域同一会话，**消息具备完整交互**（显示parsed整理信息、确认发送按钮、处理状态等）
- **焦点切换发送**：点击小窗区域后，全局输入框消息发给对应目标
  - 总监tab + 点击对话小窗 → 消息直接发对话（不经过总监）
  - 对话tab + 点击总监小窗 → 消息发给总监处理

### 1.2 约束
- 全局只有一个输入框，小窗不自带输入框
- 小窗可拖拽调宽、折叠/展开
- 原对话/轨迹功能不受影响

## 2. 现有代码分析

### 2.1 对话历史存储与读取
- **存储**：session store（`useSession` hook），按 `sessionId` 隔离共享
- **数据**：`s.chat.order`（消息key有序数组）、`s.chat.nodes`（节点数据Map）、`s.chat.timeline`、`s.queue`
- **渲染组件**：`ChatNodeSeat`（memo组件）
  - Props：`nodeKey, useSession, selectedCallId, cwd, openFile, inspectCall, forkAt, loadImage, fileMentions, renderSlot, t`
  - 内部通过 `renderSlot("conversation.chat.node", routedOwner, ...)` 渲染消息内容
  - **完整交互由 renderSlot 子组件提供**（点击详情、代码块复制、工具调用展开等），只要传递正确props即可保留全部交互

### 2.2 总监消息存储与读取
- **存储**：`directorStoreFactory(sessionId)` → 自定义store（`directorStores` Map缓存，按sessionId隔离共享）
- **数据**：`messages`（`{id, role, content, parsed?, ts}`）、`status`、`config`
- **React hook**：`useDirectorStore(store)` → useSyncExternalStore
- **渲染逻辑**（DirectorView中行7152-7173）：
  - 用户消息：右对齐蓝色背景
  - 助手消息：左对齐灰色背景，显示parsed信息（整理后指令/模型建议/分支建议），autoForward关闭时显示"确认发送"按钮
  - 系统消息：黄色背景

### 2.3 小窗当前实现
- 总监tab右侧：占位符"对话流（待实现真实嵌入）"
- 对话tab左侧：占位符"总监流（待实现真实嵌入）"
- 已支持：拖拽调宽、折叠/展开、点击设置focusTarget

### 2.4 焦点切换发送（已实现）
- `window.__directorCurrentView`：当前tab
- `window.__directorFocusTarget`：当前焦点
- `window.__directorSubmit(sessionId, draft)`：走总监流程
- `window.__directChatSubmit(sessionId, draft)`：直接发对话
- InputBar两处（键盘回车+发送按钮）根据view+focusTarget判断发送目标

## 3. 实现方案

### 3.1 组件设计

#### ChatFlow 组件（对话消息流，完整交互）
**职责**：渲染对话消息列表 + 滚动 + 加载更多，保留ChatNodeSeat全部交互

**Props**（与ChatView消息流部分一致）：
- `sessionId, useSession, useSessions, useStore, renderSlot, t`
- `openFile, loadOlder, loadImage, inspectCall, forkAt, fileMentions, chatScroll`
- `compact?: boolean`（小窗模式，减小padding和字号）

**内部逻辑**（从ChatView提取）：
1. 读取 `order, nodeStore, timeline, inbox, running, openState, openError, hasMore, loadingOlder, selectedCallId, pendingSteering, cwd`
2. 滚动容器（ref + scroll事件 + 回到底部按钮）
3. 加载更多按钮（hasMore时显示）
4. `order.map(nodeKey => <ChatNodeSeat ... />)` — **完整交互保留**
5. 运行状态指示器（TurnStatus）
6. 待处理转向气泡（PendingSteeringBubble）

**小窗适配**：
- `compact=true` 时减小padding（8px）、字号（12px）、消息气泡max-width（90%）
- 隐藏回到底部按钮（小窗空间有限）
- 隐藏加载更多按钮的完整样式，简化为文字链接

#### DirectorFlow 组件（总监消息流，完整交互）
**职责**：渲染总监消息列表 + 滚动，保留parsed信息展示和确认发送交互

**Props**：
- `sessionId`
- `onConfirmSend?: (instruction) => void`（确认发送回调，小窗中可调用window.__directChatSubmit）
- `compact?: boolean`

**内部逻辑**（从DirectorView提取）：
1. `const store = directorStoreFactory(sessionId)`
2. `const state = useDirectorStore(store)`
3. 滚动容器（自动滚动到底部）
4. 消息渲染（复用DirectorView的气泡逻辑）：
   - 用户消息：右对齐
   - 助手消息：左对齐，显示parsed信息卡片（整理后指令/模型建议/分支建议）
   - 系统消息：黄色背景
   - autoForward关闭时显示"确认发送"按钮 → 调用onConfirmSend
5. 空状态提示
6. 处理状态指示器（processing时显示"总监处理中..."）

### 3.2 小窗集成

#### 总监tab右侧对话小窗
- 替换占位符为 `<ChatFlow sessionId={sessionId} useSession={useSession} useSessions={useSessions} useStore={useStore} renderSlot={renderSlot} t={t} openFile={...} loadOlder={...} loadImage={...} inspectCall={...} forkAt={...} fileMentions={...} chatScroll={...} compact={true} />`
- DirectorView已有这些props（从inject传入）

#### 对话tab左侧总监小窗
- 替换占位符为 `<DirectorFlow sessionId={sessionId} compact={true} onConfirmSend={(instruction) => window.__directChatSubmit?.(sessionId, instruction)} />`
- ChatView已有sessionId prop

### 3.3 焦点切换（已实现，确认无误）
- 小窗容器onClick → `directorLayoutStore.setFocusTarget(...)` → 同步设置`window.__directorFocusTarget`
- InputBar发送逻辑已根据focusTarget判断
