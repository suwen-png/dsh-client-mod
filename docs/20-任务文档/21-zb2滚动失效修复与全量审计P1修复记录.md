## 二、zb2 无法滚动 — 根因

**原版机制**：消息列 `.f7fkwa_scroll` 自身不滚（注入 CSS 强制 `overflow:visible;flex:none;min-height:auto`），靠祖先 `[data-conversation-scroll]`（scrollBody）统一滚动；原版激活态 CSS 让 viewArea 随内容撑高。

| 破坏点 | 位置 | 说明 |
|:------|:-----|:-----|
| 主因 | 9878-9882 | V9.1 给 viewArea 内联 `height:100%;flex:1 1 0;minHeight:0` 钉死高度 → scrollBody scrollHeight 恒等于 clientHeight → 唯一滚动容器失效，14 处 scrollTop 写入全 no-op |
| 合谋 | 7200-7201 | 分屏外壳 `overflow:hidden` 把消息列溢出裁掉，全链路无元素可滚 |

V9.1 动机（不能直接撤销）：原机制下 scrollBody 滚动会把 b-1 固定顶栏卷走。

## 三、修复方案（V9.4：zb2 自足滚动，4 处改动）

关键支点：`scrollerOf(from)` 是 zb2 全部滚动逻辑（toBottom/follow/atBottom 监听/loadOlder 锚点/回底按钮，共 14 处）的统一容器解析入口，改此一处全部消费者自动指向新容器。

| # | 位置 | 改动 |
|:-:|:-----|:-----|
| 1 | scrollerOf(~5410) | 前置判断：元素带 `data-chat-local-scroll` 属性时直接返回自身 |
| 2 | zb2 包装 div(~7305) | style 追加 `minHeight: 0`（flex 子链允许收缩） |
| 3 | zb2 消息列 div(~7310) | 追加 `"data-chat-local-scroll": ""` + `style:{flex:"1 1 0",minHeight:0,overflowY:"auto"}`（内联压过注入 CSS 的 overflow:visible） |
| 4 | ChatFlow(~8735) | style 追加 `minHeight: 0`（预防 a2 同款塌陷，同 DirectorFlow V9.2 修复） |
