## 二、设计迭代原则

### 2.1 三条铁律

1. **不破坏现有功能** —— 所有迭代都是增量优化，不删除已有能力
2. **风格完全统一** —— 四个界面共用同一套设计令牌（颜色/字体/间距/圆角/阴影/过渡）
3. **交互可预测** —— 相同操作在不同界面产生相同结果，减少用户认知负担

### 2.2 设计令牌（V16 已有，本次强化统一）

| 令牌 | 值 | 用途 |
|:-----|:---|:-----|
| `--t` | 140ms | 统一过渡（所有交互元素） |

| `--radius-m` | 9px | 卡片/面板 |

## 三、具体迭代方案（7 项改进点的落地方案）

### 3.1 浮层切换入口统一（P1）

**现状问题**：
- FloatDock 右下角三个按钮（设计图/导图/总监）
- 总监页内也有浮层入口
- 快捷键 `Alt+1/2/3`
- 三处入口逻辑分散，用户不知道哪个是"正确"入口

**迭代方案**：
- FloatDock 为**唯一浮层切换入口**（主入口）
- 总监页内入口改为**快捷唤起**（标注"快捷"，不重复实现切换逻辑）
- 快捷键作为**键盘用户的替代入口**
- 所有入口调用同一个 `toggleOverlay(type)` 函数
- 浮层切换时显示**统一的过渡动画**（140ms 淡入淡出 + 轻微缩放）

**交互流程**：
```
用户点击 FloatDock 按钮
  → 检查当前是否有其他浮层打开
    → 有：先关闭当前浮层（140ms 淡出）
    → 无：直接打开目标浮层（140ms 淡入 + 轻微放大）
  → 更新 FloatDock 按钮状态（激活态高亮）
  → 记录到 layout store（持久化）
```

### 3.2 层级切换路径缩短（P1）

**现状问题**：
- 要求 7（点击文件夹/项目展示对应总监）已实现，但入口不明显
- 用户通常通过打开总监弹窗 → 层级选择器来切换，4 步

**迭代方案**：
- 侧栏文件夹/项目**悬浮时显示总监图标**（提示"点击查看该项目总监"）
- 点击文件夹/项目时，**如果总监弹窗未打开则自动打开**并切换到对应层级
- 如果总监弹窗已打开，**直接切换层级**（不重复打开）
- 层级切换时显示**面包屑导航**（全局 › 项目 › 文件夹 › 对话），可点击回退

**交互流程**：
```
用户点击侧栏文件夹
  → 检查总监弹窗状态
    → 未打开：打开总监弹窗（140ms 动画）
    → 已打开：不重复打开
  → 切换到对应层级节点
  → 更新面包屑导航
  → 加载该层级的总监数据（消息/记忆/职责）
  → 右侧对话数据同步切换到该文件夹下当前会话
```

### 3.3 总监页信息密度优化（P2）

**现状问题**：
- R1-R8 八区域全部展开时拥挤
- R6 记忆面板 hover 展开易误触（鼠标经过就展开，干扰阅读）

**迭代方案**：
- R2 项目总览卡片 / R4 项目导航 / R6 记忆面板**可折叠**（点击标题折叠/展开）
- 折叠状态显示摘要（如 R6 显示"3 条核心记忆 · 2 条决策"）
- R6 记忆面板改为**点击展开**（非 hover），展开后显示完整内容
- 折叠状态持久化（用户偏好）
- 首次使用时**全部展开**（让用户看到完整功能），用户折叠后记住偏好

**交互流程**：
```
用户点击 R6 记忆面板标题
  → 切换折叠/展开状态
  → 展开：显示完整记忆列表（核心记忆/决策记录/偏差风险）
  → 折叠：显示摘要（"3 条核心记忆 · 2 条决策 · 1 条风险"）
  → 持久化到 personalize store
```

### 3.4 设计图工作室顶栏响应式（P2）

**现状问题**：
- 顶栏四区（文件操作/视图切换/保存状态/窗口控制）+ 安全区避让
- 小窗口下（<800px 宽）按钮拥挤，部分按钮被截断

**迭代方案**：
- 顶栏**响应式折叠**：
  - ≥1200px：全部按钮展开
  - 800-1200px：次要按钮（导出/导入/历史）收入"更多"菜单
  - <800px：只保留核心按钮（保存/撤销/重做/关闭），其余收入"更多"菜单
- "更多"菜单为下拉面板，显示所有次要功能
- 保存状态指示器（●未保存/✓已保存）**始终可见**（不被折叠）
- 窗口控制按钮（最小化/关闭）**始终在安全区内**（不被截断）

### 3.5 思维导图节点操作发现性（P2）

**现状问题**：
- 节点有三套操作：右键菜单 / 悬浮工具条 / 快捷键
- 新用户不知道有哪些操作，发现性低

**迭代方案**：
- 节点**悬浮 500ms 后**显示**操作提示条**（在节点下方，列出最常用的 4-5 个操作图标）
- 操作提示条包含：添加子节点 / 添加兄弟节点 / 编辑 / 折叠 / 更多（右键菜单完整入口）
- 提示条**不阻挡节点点击**（点击节点仍然是选中/聚焦）
- 提示条在鼠标移开节点后**300ms 消失**（给用户时间移到提示条上）
- 首次使用时显示**一次性引导**（"右键节点查看更多操作，按 ? 查看快捷键"）

### 3.6 消息流转状态反馈（P3）

**现状问题**：
- 四维流转（总监/对话/导图/设计图）同步时无视觉反馈
- 用户不知道消息是否已同步到其他界面

**迭代方案**：
- 消息发送/流转时，**目标界面显示同步指示器**（右上角短暂显示"已同步到思维导图"提示，1.5s 后消失）
- 同步指示器为**轻量 toast**（不阻塞操作，不抢焦点）
- 如果目标界面未打开，**不显示提示**（避免干扰）
- FloatDock 对应按钮**显示未读标记**（如思维导图有新同步内容，按钮上显示小圆点）

### 3.7 错误恢复路径（P3）

**现状问题**：
- SafeLayer 捕获错误后显示空白，用户不知道怎么恢复
- 单层崩溃可能卸载整棵 Shell 根（宿主无 React 错误边界）

**迭代方案**：
- SafeLayer 错误边界显示**友好错误页**：
  - 错误图标（⚠️）
  - 错误标题（"出了点小问题"）
  - 错误描述（简洁，不显示技术栈信息）
  - **重试按钮**（重新渲染该层）
  - **恢复指引**（"如果重试无效，请重启 Harness"）
  - **错误详情折叠**（高级用户可展开查看技术详情，默认折叠）
- 重试按钮调用 `forceUpdate()` 重新渲染
- 如果重试 3 次仍然失败，显示"请重启 Harness"指引
- 错误记录到 debug 日志（便于排查）

## 四、交互流程全图（补充迭代后）

### 4.1 核心操作流转

```
用户进入 Harness
  → 总监 tab 默认打开（order:-1 排最前）
    → 总监页显示（R1-R8 八区域，可折叠）
    → 右下角 FloatDock（三浮层入口）
    → 右上角个性化面板入口

用户点击侧栏文件夹/项目
  → 总监弹窗自动打开（如未打开）
  → 切换到对应层级
  → 面包屑导航更新
  → 右侧对话数据同步

用户点击 FloatDock 设计图按钮
  → 关闭其他浮层（如有）
  → 打开设计图工作室（全屏铺满，140ms 动画）
  → 顶栏响应式布局
  → 底部专用对话

用户在设计图工作室发送消息
  → 消息走总监治理链路
  → 四维流转同步（总监/对话/导图/设计图）
  → 目标界面显示同步指示器（如已打开）
  → FloatDock 对应按钮显示未读标记（如未打开）

用户遇到错误
  → SafeLayer 捕获
  → 显示友好错误页
  → 用户点击重试
  → 重新渲染（成功→恢复 / 失败3次→指引重启）
```

### 4.2 浮层状态机

```
                    ┌─────────────┐
                    │   无浮层    │
                    │ (默认状态)  │
                    └──────┬──────┘
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
    ┌────────────┐  ┌────────────┐  ┌────────────┐
    │ 设计图工作室 │  │  思维导图   │  │  总监弹窗   │
    │ (全屏铺满)  │  │ (覆盖层)    │  │ (覆盖层)    │
    └──────┬─────┘  └──────┬─────┘  └──────┬─────┘
           │                 │                 │
           └─────────────────┼─────────────────┘
                             ▼
                    切换浮层（先关后开，140ms 过渡）
                             │
                             ▼
                    关闭浮层（回到无浮层状态）
```
