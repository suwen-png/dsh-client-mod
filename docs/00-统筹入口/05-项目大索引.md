### 一键重建全部

```bash
node dsh-director-plugin/scripts/refresh-index.mjs           # 重建三份（🔴 会写 src 的 @map 块，见下）
node dsh-director-plugin/scripts/refresh-index.mjs --safe    # 重建「不碰 src」的两份（并行开发时用）
node dsh-director-plugin/scripts/refresh-index.mjs --check   # 只对账不写（闸门 / 交付前用）
```

> 🔴 **`--safe` 为什么存在**：`gen-source-map.mjs` 会向 `src/**` 每个文件顶部**注入 `@map` 血缘块** ⇒
> **重建索引会改动源码**。跑完（非 `--safe`）必须接着 `gen-key-files → build → plugin-install`，
> 否则产物与 src 不一致（`check-stale-build.mjs` 会红）。与其它会话并行改 `src/**` 时一律用 `--safe`。

单独重跑一份：

```bash
node scripts/gen-project-index.mjs                            # 全资源确定索引
node dsh-director-plugin/scripts/gen-source-map.mjs           # 源码映射索引
node dsh-director-plugin/scripts/gen-docs-index.mjs --check   # 文档索引（加 --check 只对账）
```

**改动后何时必须重建**：新增/删除 `src/**` 文件 · 新增/删除 `docs/**` 文档 · 新增/删除 `scripts/**` 脚本 ·
改了任何文件顶部 JSDoc 首行（它是"职责"的事实来源）。**交付封存前必跑 `--check`。**

## 六、索引一致性闸门

|:-----|:-----|:-----|
| 三份自动索引与磁盘一致 | `node dsh-director-plugin/scripts/refresh-index.mjs --check` | `IS_PASS: TRUE` |
