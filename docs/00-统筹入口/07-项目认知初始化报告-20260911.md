## 二、整体架构

### 2.1 运行时三层架构（Harness 原生）

```
① 前端渲染层（Electron Renderer）
   从 app.asar 加载主框架 index-DyLP6TCW.js（约 432KB）
   定义 window.__ModuleLoader__，按需动态加载插件 JS
        │ HTTP
② 后端服务层（Node.js Web Server，dsh-web-app / dsh-host-webserver）
   提供前端静态资源（dsh-web-frontend/dist）
   提供插件 JS（/plugins/<id>/client.js?rev=...）
        │ require()
③ 插件模块层（node_modules/@deepseek-ai/*）
   8 个目标包中目前仅 dsh-client-ui-conversation 被实际修改
```

**关键事实**：前端打包文件**不含**插件代码；插件通过 `window.__ModuleLoader__.load({ id, factory })` 注册。**不要改前端打包文件**（踩坑 6）。

### 2.2 本项目的双链路改造架构

| 链路 | 载体 | 现状 |
|:-----|:-----|:-----|
| **A. 宿主补丁链路** | `workspace/@deepseek-ai/<pkg>/lib/*.js` → `apply.ps1` 文件级复制到安装目录 | ✅ 在用。仅 conversation 1 个文件，1,479,577 B，与安装目录 MD5 一致；保留 MOD-A 左栏 + directorStores/directorProcess/IDB 共享设施（《锚点契约》） |
| **B. 插件链路** | `dsh-director` 插件包（`dsh.client` 声明 → host 增量扫描 → bundle 由 webserver 提供 → cordis Loader 装载） | ⚠️ 通道已验证成功（曾以 rev `ce516814c17c` / `dd46d1352b43` 运行、`.dsh-dir-app` 挂载实证），但**当前源码目录为空、未注册** |

**插件官方通道五步**（50-信息中心/插件加载通道勘察-20260907.md）：
`package.json 声明 dsh.client` → `host dsh-client-modules 增量扫描（plugin-set 变更需重启）` → `bundle 经 /plugins/<id>/client.js 提供 + index.html 注入 __DSH_BOOT__` → `浏览器 prefetch → cordis Loader 逐行 create` → `全 ACTIVE 后 settled`。

## 八、主要业务逻辑与关键数据流

### 8.1 总监对话主链路（转发 + 本地预处理）

```
用户在总监 tab 输入
  → InputBar.onKeyDown / 发送按钮 onClick
    → window.__directorSubmit(text)
      → directorProcess(text)                     [总监处理函数]
          ├─ callLocalModel()  → Ollama /api/chat  (qwen2:7b，含流式；不可用时降级规则模板)
          └─ 输出解析 → { instruction / model / branch / reasoning }
      → sendToChat(text) → sendSession(session, text, [], "queue")
        → session.prompt(content, "queue")        [mode 必须是 queue]
      → 消息落 directorStore（localStorage + IDB，按 sessionId 隔离）
```
三 tab（总监 / 对话 / 轨迹）**数据共享**，原功能 100% 保留；全局单输入框按「当前 tab + 焦点」路由到目标。

### 8.2 布局状态流
`directorLayoutStore`（宽度 / 折叠 / 焦点）→ localStorage → 每次渲染由 `useLayoutEffect` 修正 `window.__directorCurrentView`（因 inject 返回的 currentView 是静态快照——踩坑 8）。

### 8.3 资产 / 索引数据流（apply 时自动）
```
workspace 文档树 ──gen-docs-index.ps1──► docs-index.json ──注入──► client.js（只读 DSH_DOCS_INDEX）
workspace/scripts/snapshots/docs ──apply.ps1──► config/assets.json（packages/snapshots/docs/scripts/codeLines）
```
最近一次实测值（2026-09-08 13:14）：文档 90 / 脚本 12 / 快照 57 / clientJs 11,977 行。

### 8.4 插件运行时数据流
`cordis Loader 装载插件 → 客户端 bundle 挂载 .dsh-dir-app → 数据读写 .dsh/director/`（`conversations/`、`projects/`、`memory/default.json`）。

### 8.5 回滚数据流（三层保障）
`restore.ps1`（回到 original） → `snapshots/`（58 份 apply 前状态） → `git revert`（本仓）；插件侧另有 git 基线 `12907c6` + 可重放构建。
