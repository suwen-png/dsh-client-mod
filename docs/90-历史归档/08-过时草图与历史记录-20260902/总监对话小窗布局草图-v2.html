交互逻辑说明

核心原则：全局只有一个输入框，根据鼠标点击的焦点区域决定提交目标。


1. 焦点切换：

  • 点击任意区域（主区域或小窗）→ 该区域获得焦点，蓝色边框高亮
  • 全局输入框左侧显示当前目标徽章（→ 总监 / → 对话）
  • 输入框 placeholder 同步显示当前目标说明

2. 消息提交：

  • 焦点在总监区域（主区域或小窗）→ 消息经总监预处理 → 自动转发到对话
  • 焦点在对话区域（主区域或小窗）→ 消息直接发给对话（原逻辑不变）
  • 按回车或点击发送按钮提交

3. 小窗特性：

  • 小窗只显示对话流，没有独立输入框
  • 拖拽中间分隔条调节宽度（最小180px，最大55%）
  • 宽度记忆：下次打开保持上次调节的宽度
  • 小窗可折叠/展开（点击标题栏的折叠按钮）
  • 小窗内消息流独立滚动，不影响主区域

4. Tab 切换：

  • 总监 Tab：总监主区域在左 + 对话小窗在右
  • 对话 Tab：总监小窗在左 + 对话主区域在右
  • 轨迹 Tab：无小窗，保持原逻辑
  • 切换 Tab 时，焦点默认在主区域
