对话流程测试清单

  • ✅ 正常对话：输入消息 → 发送 → 显示AI回复
  • ✅ 智能体切换：点击"切换对话" → 清空对话 → 加载智能体系统提示词 → 发送消息
  • ✅ 执行逻辑应用：点击"应用逻辑" → 添加系统提示词 → 后续回复按逻辑执行
  • ✅ 技能触发：输入触发词（如/code） → 自动加载技能提示词
  • ✅ Ollama降级：Ollama未启动 → 显示警告 → 使用模拟回复
  • ✅ 多轮对话：连续发送多条消息 → 上下文保持
  • ✅ 空消息保护：输入为空 → 发送按钮禁用
  • ✅ 处理中状态：发送后 → 显示"正在思考" → 禁止重复发送

两种总监模式

  • 模式1：正常对话加总监 — 在对话页面左下角点击总监按钮，弹出总监面板，不覆盖原对话
  • 模式2：覆盖式总监 — 点击顶部"总监"tab，总监页面覆盖原对话，右上角有x关闭按钮

美化要点

  • 渐变主色：#667eea → #764ba2（紫色渐变，优雅专业）
  • 卡片hover：上浮2px + 阴影 + 边框变色
  • 按钮hover：上浮1px + 阴影
  • 状态指示灯：脉冲动画
  • 进度条：渐变填充 + 过渡动画
  • 圆角统一：导航8px / 卡片10px / 按钮6-10px
  • 阴影层次：卡片0 2px 8px / hover 0 4px 12px / 弹窗0 20px 60px
  • 间距系统：4px / 8px / 12px / 16px / 20px / 24px
