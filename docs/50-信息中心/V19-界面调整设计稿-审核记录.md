## 一、第 1 轮审核

| 维度 | 得分 | 问题 |
|:-----|:----:|:-----|
| 完整性 | 1/2 | ① 板块 C 只说了「中间态缺失」，**漏掉真实根因的另一半**：R4/R7 的 `S.sec` 盒子没有 `flex:1`（R5 有）⇒ 盒子只有内容高度、下方留白 —— 这才是「没有占据整列」的现场（源码 `DirectorPage.js:717–728` / `808–832`）。② 板块 A1 只给「按文本全等定位后上溯 2 层」，**没给可执行判据** |
| 准确性 | 1/2 | 板块 A3 **推荐口径与实际不符**：推荐 ②（插件侧补齐最小化），但实测宿主那枚 `—` 按钮调的 `directorLayoutStore.toggleDirectorCollapsed()` 是**宿主自己的** store（`client.js:7340`），**不是**已无定义的 `handleAgentClick` ⇒ 它**本来就能用**，是被 `up:1` 一起隐掉了。推荐 ② 会让用户少看到一个本可用的按钮 |
| 可执行性 | 1/2 | 板块 A1 的护栏写成「须 closest 到 `.RWZidW_viewArea` 且不在插件容器内」，但**插件自己的视图就渲染在 viewArea 内**（`slots.register("conversation.view", …)`）⇒ 两条护栏**有顺序要求**却未写明，照写会形同虚设 |
| 规范性 | 1/1 | 卫生闸门 5/5 · 与 V16/V18 同源 CSS 变量 · 板块编号连续 |
| 一致性 | 1/1 | 与 V18 的对位表逐条可查（4 条沿用 + 6 条新增） |
| 风险覆盖 | 1/1 | 含护栏正负对照、持久化字段留而不删、降级口径（"降级可以，无声不行"） |
| 可验证性 | 0/1 | 板块 A2 的「同步处理 addedNodes」**未发现** `markersAlive()` 的语义缺陷：它要求 `marked.length >= TRIM_TARGETS.length`；本批一旦加第 3 个目标（对话页标题栏），在**总监页**（ChatView 未挂载）该条件**永远为 false** ⇒ 每次 DOM 变动都全量扫描 —— 设计稿写"保留 markersAlive() 快速返回"，而那个快速返回在本批改动后**正好失效** |

**第 1 轮总分：6/10**

**整改清单（6 项）：**
1. **板块 A3（口径）**：改为**主推 ①**（`up:1` → `up:0`，只隐「总监对话」文字、保留宿主那枚有效的 `—` 按钮）；② 降为补充说明，并写明"② 所要的插件侧入口**已存在**（`DirectorDialog` 的 `d-min`）"→ 见 `DirectorDialog.js:644/671`。
2. **板块 A1（判据）**：补可执行判据 —— 目标元素 = `<div>`，`children.length === 2`，`children[0]` 是 `<span>` 且文本全等 `对话`，`children[1]` 是 `<div>` 且其后代 `<button>` 恰 **5** 个、文案依次为 **代码/文档/调研/测试/审核**。
3. **板块 A1（护栏顺序）**：显式写明顺序 —— 先排除"落在插件自挂容器内"，再要求"能 closest 到 viewArea 且**不在** `[style*="min-width: 180px"]` 面板内"。
4. **板块 A2（性能）**：改写为 —— 回调内**同步**只扫 `record.addedNodes` 子树（不全文扫描），并把 `markersAlive()` 语义从「标记数 == 目标数」改为「**已贴的标记都还连着**」。
5. **板块 C（根因）**：补上「盒子缺 `flex:1` ⇒ 不占整列」这半边，并明确 `align-items:stretch` + `height:100%` 的落地写法。
6. **板块 E（实现层次）**：把"改走 `sendToHost`"改为"改走 **`deliverToChat(text, {sessionId, opener})`**" —— 后者内部**首选**就是 host-send，且带 `opener` 兜底与 `lastDeliver` 留痕；直接调 `sendToHost` 会丢掉这两样（`chat-bridge.js:250–296`）。

（整改后进入第 2 轮）

## 五、审核结论

- **第 4 轮达 10/10，审核闭环**（≥3 轮，每轮有整改项，整改后重审）。

  4. 板块 C 的根因**漏了一半**（盒子缺 `flex:1`）。
- **核心度**：10 条需求全部直击，无跑偏；唯一"多余物"是评审用施工单（不改变界面）。
