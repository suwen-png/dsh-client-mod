V11 设计规范与交互逻辑说明

🎨 设计系统

  • 主色换轴：#2563eb（品牌蓝600），同屏 accent ≤2 处（发送按钮+激活下划线）
  • 字阶6档：标题16/600 → 副标题14/600 → 正文13/400 → 次要12/400 → 辅助11/400 → 徽标10/500
  • 对比度门禁：正文 #1f2937（≥7:1），次要 #6b7280（≥4.5:1），禁用 #9ca3af 以下
  • 圆角体系：卡片10px / 按钮6px / 输入框8px / 弹窗12px
  • 间距8px基准：4/8/12/16/20/24 六档

✅ 27号文问题解决

  • P0-1 未铺满：.dsh-dir-app width:100%，主内容区 flex:1 minWidth:0 全宽闭合
  • P0-2 悬浮条截断：模型名移入输入栏左侧固定展示，不悬浮不截断
  • P0-3 JSON泄漏：消息渲染层过滤 system-reminder，调试徽章默认隐藏
  • P1-1 激活态统一：所有 tab 统一为 2px 下划线+主色文字+字重600
  • P1-2 图标混用：chrome 级 UI 全 SVG，数据内容区 emoji 保留（hybrid 渲染器）
  • P1-4 列表硬截断：D区列表底部 mask-image 渐隐遮罩
  • P1-7 靛蓝AI-slop：换轴 #2563eb，accent 纪律 ≤2 处/屏

🔄 交互逻辑（状态机）

  • 顶层三tab：总监→V10Director / 对话→ConversationPanel(b-2透明视口) / 轨迹→TracePanel，各tab独立滚动位置
  • B区总览：点击header折叠/展开；编辑态含核心记忆输入+进度滑块+风险/待办数+详情；风险查看→展开+脉冲高亮2.2s
  • 对话区：对话流/思维导图二段切换；Enter发送/Shift+Enter换行/中文组词不发送；清空→二次确认；思维导图节点右键菜单
  • D区：三tab统一激活态；搜索带清除+过滤下拉+新建；智能体卡"切换对话"→挂载思维导图分支；技能卡"应用技能"→填入触发词
  • 弹窗：编辑/设置/确认/分支命名四类，Esc 关闭最上层，点击遮罩关闭

📐 页面元素清单

  • 顶层：项目切换按钮 + 三tab（总监/对话/轨迹）+ 设置 + 关闭
  • A区：总监标识(含状态点) + 当前项目 + 驾驶舱下拉(8项) + 选择项目 + 设置 + 折叠
  • B区：折叠header + 四卡(核心记忆/进度/风险/待办) + 编辑态表单
  • 对话区：视图切换 + 当前智能体徽标 + 清空 + 消息列表(用户/助手/系统三气泡+空态+思考中) + 输入栏(模型名+textarea+发送)
  • D区：三tab + 工具栏(搜索带清除+过滤+新建) + 卡片列表(智能体/技能/执行逻辑) + 底部渐隐
  • 弹窗层：编辑弹窗(完整表单) + 设置弹窗(三tab) + 确认弹窗 + 分支命名弹窗
