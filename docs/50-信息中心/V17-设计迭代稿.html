FloatDock 统一入口（激活态 + 未读标记 + 工具提示）

改进点 1/6
B1

FloatDock — 统一浮层切换入口

三按钮调用同一 toggleOverlay · 激活态高亮 · 未读标记小圆点
FloatDock 行为规范：
• 三个按钮调用同一个 toggleOverlay(type) 函数
• 切换浮层时：先关当前（140ms 淡出）→ 再开目标（140ms 淡入+轻微放大）
• 激活态：按钮背景变蓝 + 3px 蓝色光晕
• 未读标记：目标浮层未打开时有新内容 → 右上角红色小圆点
• 工具提示：悬浮显示按钮名称（140ms 淡入）
◈设计图工作室（Alt+1）
❖思维导图（Alt+2）· 有新同步
◆总监弹窗（Alt+3）
▲ FloatDock：◈ 设计图（激活态·青色）· ❖ 导图（未读标记·紫色）· ◆ 总监（蓝色）· 悬浮显示工具提示
改进点说明：FloatDock 为唯一浮层切换入口（主入口），总监页内入口改为快捷唤起，快捷键作为键盘用户替代入口。所有入口调用同一函数，切换逻辑一致。浮层未打开时有新内容时，按钮显示未读标记（红色小圆点）。

改进点说明：节点有三套操作（右键菜单 / 悬浮工具条 / 快捷键），新用户发现性低。新增操作提示条：节点悬浮 500ms 后在节点下方显示，列出最常用的 4-5 个操作图标。提示条不阻挡节点点击，鼠标移开 300ms 后消失（给用户时间移到提示条上）。首次使用时显示一次性引导（"右键节点查看更多操作，按 ? 查看快捷键"）。
