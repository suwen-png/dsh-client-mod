## 一、通道七步链路（勘察实证）

```
① 包声明        package.json 写 dsh.client: { platform:"web", inject:[包名…], immediately?:bool }
② host 装载      包成为 host Loader（cordis）entry
③ 增量扫描       dsh-client-modules 监听 cordis internal/plugin 事件，扫描 dsh.client 声明
                 （"Package metadata cached per name and never expires — plugin-set changes take effect on restart"）
④ bundle 服务    host webserver 挂路由 GET /plugins/<id>/client.js（clientPath 缺失 → MissingClientBundleError，提示先 build）
⑤ 清单注入       tapIndex 把 __DSH_BOOT__（rev + modules 视图 + plugins 视图）注入 index.html <head> 首个 script
⑥ 浏览器 boot    AppWebEntry.run(): parseBootManifest → ClientModuleSystem(staticModules) → prefetch immediately 层
                 → cordis Loader 逐行 create → loader.await() → 全 fiber ACTIVE sweep（fail-loud）
⑦ 插件激活       bundle factory 在 __ModuleLoader__.load({id, factory(require)}) 内执行，ctx.slots/ctx.reflect 接线
```

## 三、开源调研（T-PLUG-002）

- **Cordis 是成熟开源插件内核**：Koishi 框架四年基础，现为 DeepSeek Harness 的插件内核（来源：floatboat.ai《Cordis — The Plugin Kernel Behind DeepSeek Harness》2026-08-14；npm @deepseek-ai/cordis 2026-08-13）。
- **官方教程存在**：`github.com/deepseek-ai/deepseek-harness/blob/master/docs/cordis-tutorial/index.md` ——「Cordis is the plugin framework underneath DeepSeek Harness」。插件开发不必自研内核知识，直接跟官方教程。
- 核心概念：Plugin 是蓝图、Fiber 是挂载档案、六状态（PENDING/LOADING/ACTIVE/FAILED/DISPOSED/UNLOADING）——与 E4 web 侧 STATE_LABELS 镜像一致。
