## 二、持久化相关修改

### M1: safeDirectorKey — 固定持久化key

**位置**: 第5906-5909行
**函数**: `safeDirectorKey(sessionId)`
**修改前**:
```javascript
function safeDirectorKey(sessionId) {
    if (typeof sessionId === "string" && sessionId.length > 0) return sessionId.replace(/[^a-zA-Z0-9_-]/g, "_").slice(0, 64);
    return "default";
}
```
**修改后**:
```javascript
function safeDirectorKey(sessionId) {
    // V9修复: 总监是全局大总监，使用固定key持久化
    // 原实现使用sessionId(UUID)，每次启动都不同，导致持久化完全失效
    return "director-main";
}
```
**目的**: 原实现使用sessionId(UUID)作为key，每次启动sessionId都不同，导致持久化完全失效。改为固定key"director-main"，确保每次启动都能加载到同一份数据。
**影响的key**: `dsh.director.store.director-main`（localStorage和IndexedDB共用）

### M2: loadDirectorStore — 加载诊断log

**位置**: 第5911-5931行
**函数**: `loadDirectorStore(sessionId)`
**修改内容**: 在`no data`分支增加诊断log，输出localStorage中所有以`dsh.director`开头的key及其字节数。
**新增代码**:
```javascript
// V9.2: 输出所有以dsh.director开头的key，诊断数据是否存在
let allKeys = "";
try {
    for (let i = 0; i < localStorage.length; i++) {
        const k = localStorage.key(i);
        if (k && k.indexOf("dsh.director") === 0) allKeys += k + "(" + (localStorage.getItem(k) || "").length + "bytes) ";
    }
} catch (e) { allKeys = "enumerate failed: " + e.message; }
window.__dshDebug.log("persist", "load: no data for key=" + key + " | all director keys: [" + (allKeys || "none") + "]");
```
**目的**: 诊断数据是否真的在localStorage中。如果`all director keys`为空，说明数据没写入；如果有其他key，说明key不匹配。

### M4: beforeunload — 退出前强制保存

**位置**: 第6047-6063行（`useDirectorStore`函数之后）
**目的**: Electron的localStorage是异步持久化的，如果应用快速退出或被杀进程，数据可能没写入磁盘。beforeunload事件在页面前确保再次写入，提高持久化成功率。

## 三、布局/滚动相关修改

### M5: DirectorFlow根容器 — minHeight:0 滚动修复

**位置**: 第6432-6436行
**组件**: `DirectorFlow`（a-2小窗和b-2小窗共用）
**目的**: 在flex column布局中，子元素默认`min-height:auto`，会被内容撑开，导致`overflow:auto`不生效。增加`min-height:0`后，子元素可以收缩到小于内容高度，`overflow:auto`生效。

---

### M6: viewArea — 固定布局修复

**位置**: 第9074-9078行
**组件**: `ConversationSession`的根容器（viewArea）
**目的**: 原CSS在`data-phase=active`时，viewArea高度由内容撑开，scrollBody滚动时整个viewArea跟着滚动，蓝色栏不固定。
