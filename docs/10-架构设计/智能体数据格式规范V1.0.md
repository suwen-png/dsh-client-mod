# 智能体（Agent）数据格式规范 V1.0

> **文档定位**：定义 dsh-client-mod 项目中智能体（Agent）的数据结构、字段规范、图标标准、边界约束和保存机制。
> **创建日期**：2026-09-03
> **适用范围**：`config/agents.json`、D区智能体面板、编辑弹窗、分支创建逻辑

---

## 一、数据结构定义

### 1.1 完整字段列表

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|:-------|:-----|:----:|:-------|:-----|
| `id` | string | ✅ | - | 智能体唯一标识，英文小写，用连字符分隔，如 `code-engineer` |
| `name` | string | ✅ | - | 智能体显示名称，中文，2-10个字符 |
| `icon` | string | ✅ | 🤖 | 智能体图标，使用 Emoji，1个字符 |
| `color` | string | ❌ | #1976d2 | 主题色，十六进制，用于标签和边框高亮 |
| `description` | string | ✅ | - | 简短描述，10-50个字符，说明智能体核心能力 |
| `systemPrompt` | string | ✅ | - | 系统提示词，定义智能体角色、能力、回答格式，50-500字 |
| `enabled` | boolean | ❌ | true | 是否启用，禁用后不在列表中高亮显示 |
| `model` | string/null | ❌ | null | 指定模型，null表示使用默认模型 |
| `category` | string | ❌ | general | 分类：development / document / analysis / general |
| `callCount` | number | ❌ | 0 | 调用次数统计，自动累加 |
| `createdAt` | number | ❌ | Date.now() | 创建时间戳（毫秒） |
| `updatedAt` | number | ❌ | Date.now() | 更新时间戳（毫秒） |
| `refDocs` | array | ❌ | [] | 引用文档列表，每个元素为 `{docId, title, path}` |
| `tags` | array | ❌ | [] | 标签列表，用于筛选和分类 |
| `temperature` | number | ❌ | 0.7 | 生成温度，0-1之间 |

### 1.2 JSON 示例

```json
{
  "id": "code-engineer",
  "name": "代码工程师",
  "icon": "💻",
  "color": "#1976d2",
  "description": "资深全栈开发，擅长代码生成、调试、架构设计",
  "systemPrompt": "你是一位资深软件工程师，拥有10年以上全栈开发经验。...",
  "enabled": true,
  "model": null,
  "category": "development",
  "callCount": 0,
  "createdAt": 1756800000000,
  "updatedAt": 1756800000000,
  "refDocs": [
    { "docId": "doc-001", "title": "代码规范", "path": "docs/10-架构设计/代码规范.md" }
  ],
  "tags": ["开发", "全栈", "代码生成"],
  "temperature": 0.7
}
```

## 二、图标标准

### 2.1 图标规范

- **格式**：使用标准 Emoji 字符，1个 Unicode 字符
- **尺寸**：显示时 22px（D区方框）/ 16px（列表项）
- **分类推荐**：

| 分类 | 推荐图标 | 说明 |
|:-----|:---------|:-----|
| 开发类 | 💻 🛠️ ⚙️ 🔧 🚀 | 代码工程师、架构师等 |
| 文档类 | 📄 📝 📋 📚 ✍️ | 文档专家、技术写作等 |
| 分析类 | 🔍 📊 📈 🔬 🧪 | 调研分析师、数据分析师等 |
| 测试类 | 🧪 ✅ 🐛 🔎 🛡️ | 测试工程师、质量保障等 |
| 审核类 | 🔎 ⚖️ 📋 ✅ 🛡️ | 审核专家、合规审查等 |
| 通用类 | 🤖 👤 🎯 🧠 ⭐ | 通用助手、个人助理等 |

### 2.2 图标边界

- ✅ 允许：标准 Emoji（Unicode 6.0+）、单字符
- ❌ 禁止：图片URL、SVG、多字符组合、自定义图标字体
- ⚠️ 注意：部分 Emoji 在不同平台显示不同，优先使用兼容性好的基础 Emoji

## 三、信息边界约束

### 3.1 字段长度限制

| 字段 | 最小长度 | 最大长度 | 校验规则 |
|:-----|:--------:|:--------:|:---------|
| `id` | 2 | 32 | 英文小写+数字+连字符，必须以字母开头 |
| `name` | 2 | 10 | 中文/英文，不允许特殊字符 |
| `description` | 10 | 50 | 中文/英文，简要描述核心能力 |
| `systemPrompt` | 50 | 2000 | 完整的角色定义和行为规范 |
| `category` | - | 20 | 必须是预定义分类之一 |
| `tags` | 0 | 10个 | 每个标签2-10个字符 |
| `refDocs` | 0 | 20个 | 每个引用必须包含docId和title |

### 3.2 内容规范

**systemPrompt 必须包含**：
1. 角色定义（你是谁）
2. 核心能力（你擅长什么）
3. 回答格式（如何组织输出）
4. 行为约束（不能做什么）

**description 应该**：
- 一句话概括核心能力
- 包含2-3个关键词
- 避免与name重复

### 3.3 唯一性约束

- `id` 全局唯一，不允许重复
- `name` 建议唯一，但允许重复（会显示id区分）
- 创建时自动检查id是否已存在

## 四、保存机制

### 4.1 保存流程

```
用户点击保存
    ↓
1. 前端校验（必填字段、长度限制、格式校验）
    ↓ 校验失败 → 显示错误提示，不保存
2. 生成/更新元数据（updatedAt、createdAt）
    ↓
3. 更新内存中的 v10Data.agents
    ↓
4. 写入 config/agents.json（通过 apply.ps1 或直接文件写入）
    ↓
5. 关闭弹窗，刷新列表显示
    ↓
6. 显示保存成功提示
```

### 4.2 保存方式

| 场景 | 保存方式 | 说明 |
|:-----|:---------|:-----|
| 新建智能体 | 追加到数组 | 自动生成id、createdAt、callCount=0 |
| 编辑智能体 | 替换对应元素 | 更新updatedAt，保留createdAt和callCount |
| 启用/禁用 | 更新enabled字段 | 不修改其他字段 |
| 删除智能体 | 从数组移除 | 不可恢复，建议先确认 |

### 4.3 文件格式

- 文件路径：`D:\hermes-data\dsh-client-mod\config\agents.json`
- 编码：UTF-8（无BOM）
- 格式：标准JSON，2空格缩进
- 数组顺序：按createdAt降序（最新的在前）

## 五、与技能（Skill）的区别

| 维度 | 智能体（Agent） | 技能（Skill） |
|:-----|:----------------|:--------------|
| 定位 | 完整的角色定义，包含系统提示词 | 特定功能的触发词+Prompt |
| 触发方式 | 点击创建分支，整个对话使用该角色 | 输入 `/trigger` 触发，单次生效 |
| 核心字段 | systemPrompt（角色定义） | trigger + prompt（触发词+提示词） |
| 持续时间 | 整个分支会话 | 单次消息 |
| 图标 | 角色相关Emoji | 功能相关Emoji |
| 引用文档 | 支持（角色知识库） | 支持（功能参考文档） |

## 七、修改指南

### 7.1 新增字段

1. 在本文档"数据结构定义"中添加字段说明
2. 更新 `config/agents.json` 中的预设数据
3. 更新 `client.js` 中编辑弹窗的表单字段
4. 更新 `saveDModal` 函数的保存逻辑
5. 更新D区列表项的显示逻辑（如需要）

### 7.2 修改预设智能体

1. 直接修改 `config/agents.json`
2. 运行 `apply.ps1` 重新生成索引
3. 重启Harness生效

### 7.3 代码修改位置

| 功能 | 文件 | 位置 |
|:-----|:-----|:-----|
| 数据加载 | client.js | `loadV10Config` 函数 |

| 编辑弹窗 | client.js | `dModal && dModal.open` 弹窗 |
| 保存逻辑 | client.js | `saveDModal` 函数 |
