# 02 - 复原手册

> 文档编号：DSH-MOD-RESTORE-02 ｜ 版本：V1.0 ｜ 日期：2026-08-24
> 用途：Harness 出问题时的快速复原指南。按场景选择对应操作。

## 场景一：修改后 Harness 启动报错 / 白屏 / 功能异常

**症状**：apply 修改后，Harness 启动报错、白屏、或某个功能异常。

**操作**：
```powershell
cd D:\hermes-data\dsh-client-mod\scripts

# 1. 先查看哪些包被修改了
.\status.ps1

# 2. 一键复原所有包到原始状态
.\restore.ps1

# 3. 确认复原成功
.\status.ps1
# 所有包应显示 ORIGINAL 状态

# 4. 完全退出 Harness 后重启
```

**原理**：`restore.ps1` 删除原安装目录中的 Junction，从 `original/` 复制原始文件回去。

---

## 场景二：只有某个包的修改有问题

**症状**：确定是某个特定包（如 dsh-client-ui-layout）的修改导致问题。

**操作**：
```powershell
cd D:\hermes-data\dsh-client-mod\scripts

# 只复原单个包
.\restore.ps1 -Package dsh-client-ui-layout

# 确认
.\status.ps1
# dsh-client-ui-layout 应为 ORIGINAL，其他包保持 MODIFIED

# 完全退出 Harness 后重启
```

---

## 场景三：想回退到上一次 apply 前的工作区状态

**症状**：当前 workspace 的修改有问题，想回到上一次 apply 前的快照。

**操作**：
```powershell
cd D:\hermes-data\dsh-client-mod\scripts

# 1. 查看可用快照
Get-ChildItem ..\snapshots -Directory | Sort-Object Name -Descending

# 2. 选择要回退的快照，手动复制回 workspace
#    例如回退到 snapshot-20260824-100000-before-apply
$snap = "..\snapshots\snapshot-20260824-100000-before-apply"
$ws = "..\workspace\@deepseek-ai"
foreach ($pkg in Get-ChildItem $snap -Directory) {
    $dest = Join-Path $ws $pkg.Name
    if (Test-Path $dest) { Remove-Item $dest -Recurse -Force }
    Copy-Item $pkg.FullName $dest -Recurse -Force
}

# 3. 重新应用
.\apply.ps1
```

---

## 场景四：original/ 备份损坏或丢失

**症状**：`original/` 目录被误删或损坏，无法复原。

**操作**：
```powershell
cd D:\hermes-data\dsh-client-mod\scripts

# 重新从原安装目录备份（如果原安装目录还是原始状态）
.\backup.ps1 -Force

# 如果原安装目录已经被 Junction 替换，先从 Harness 安装包重新安装，
# 或从其他机器复制原始文件，再运行 backup.ps1
```

**预防**：`original/` 是只读复原源，不要在其中修改文件。定期将 `original/` 打包备份到其他位置。

---

## 场景五：Junction 状态异常（指向错误位置）

**症状**：`status.ps1` 显示 `JUNCTION_OTHER`，即 Junction 指向了非 workspace 的位置。

**操作**：
```powershell
cd D:\hermes-data\dsh-client-mod\scripts

# 手动删除异常 Junction（确认是 Junction 后才删）
$pkgPath = "D:\软件安装\...\node_modules\@deepseek-ai\dsh-client-ui-layout"
if ((Get-Item $pkgPath -Force).Attributes -band [IO.FileAttributes]::ReparsePoint) {
    Remove-Item $pkgPath -Force
    Write-Host "已删除异常 Junction"
}

# 从 original 复原
.\restore.ps1 -Package dsh-client-ui-layout

# 或重新应用 workspace
.\apply.ps1
```

## 紧急复原速查表

| 操作 | 命令 | 影响范围 |
|------|------|---------|
| 全量复原 | `.\restore.ps1` | 所有 7 个包 |
| 单包复原 | `.\restore.ps1 -Package <name>` | 指定包 |
| 查看状态 | `.\status.ps1` | 只读 |
| 查看差异 | `.\diff.ps1` | 只读 |
| 应用修改 | `.\apply.ps1` | 所有 7 个包 |
| 手动快照 | `.\snapshot.ps1 -Label <name>` | workspace 备份 |
