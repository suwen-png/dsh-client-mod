# A 区 · 整合导航栏详细设计文档

> **版本**: V10-design-v1.0
> **日期**: 2026-09-02
> **区域定位**: 总监页面顶部固定导航栏（原 A 区 + C 区整合），高度固定 40px
> **设计原则**: 一屏可见核心操作，次要操作收入设置弹窗，状态一目了然

---

## 一、区域概述

A 区是总监页面的顶部导航栏，整合了原 A 区（项目/阶段/驾驶舱）和原 C 区（状态/自动转发/导出日志/设置）的所有功能。高度固定 40px，不随 B 区折叠而变化。

### 布局结构（从左到右）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 🎯总监 │ 📁dsh-client-mod ▾ │ 🏷️阶段 V9 │ 🚀驾驶舱 │        │ b0902-1033 │ ⚙️ │
└─────────────────────────────────────────────────────────────────────────────┘
   ①        ②                  ③          ④        ⑤         ⑥          ⑦
```

| 序号 | 元素 | 宽度 | 说明 |
|:----:|------|------|------|
| ① | 🎯总监 tab | 自适应 | 当前激活态，带状态指示点 |
| ② | 📁项目选择 | 自适应 | 点击展开项目列表下拉 |
| ③ | 🏷️阶段 | 自适应 | 显示当前阶段+徽标，点击编辑 |
| ④ | 🚀驾驶舱 | 自适应 | 点击展开快捷操作面板 |
| ⑤ | 弹性空白 | flex:1 | 左右分隔 |
| ⑥ | 版本号 | 自适应 | 只读，来自文档索引时间戳 |
| ⑦ | ⚙️设置 | 32px | 点击展开设置弹窗（4 tab） |

## 二、元素详细设计

### 2.1 ① 🎯总监 tab（含状态指示点）

**功能**: 标识当前在总监视图，显示总监当前运行状态

**状态指示点**（在"总监"文字左侧，6px 圆点）:
- 🟢 绿色 = 待命（idle）
- 🟡 黄色 = 处理中（processing / calling-local-model）
- 🔴 红色 = 错误（error）
- ⚪ 灰色 = 未连接 Ollama（本地模型不可用）

**交互**:
- 点击 = 切换到总监 tab（如果在其他 tab）
- 悬停 = 显示 tooltip："总监状态：待命 / 处理中 / 错误"

**数据来源**: `state.status`（已有 state，无需新增）

---

### 2.2 ② 📁项目选择

**功能**: 显示当前项目名称，点击展开项目列表下拉，切换项目

**下拉列表内容**:
- 项目列表（来自 `projects` state），每项显示：📁 + 项目名称 + 路径（小字）
- 当前项目左侧有 ✓ 标记
- 列表底部："+ 管理项目"入口（打开项目管理面板，后续版本）

**切换行为**:
1. 保存当前项目对话历史到 `dsh.director.store.project.{projectId}`
2. 加载新项目数据（对话历史/项目总览/任务/技能配置）
3. 更新 `currentProject` state
4. 显示 toast："已切换到项目：{name}"

**数据来源**: `projects` / `currentProject`（已有 state）

---

### 2.3 ③ 🏷️阶段标签

**功能**: 显示当前项目所处阶段，点击可快速编辑

**预设阶段列表**（下拉选择）:
| 阶段 | 徽标颜色 | 说明 |
|------|---------|------|
| 需求分析 | 灰色 #9e9e9e | 需求收集和分析阶段 |
| 设计中 | 蓝色 #1976d2 | 架构/UI/方案设计阶段 |
| 开发中 | 橙色 #f57c00 | 编码实现阶段 |
| 测试中 | 紫色 #7b1fa2 | 测试/验证阶段 |
| 已发布 | 绿色 #388e3c | 已上线/已交付 |
| 维护中 | 青色 #0097a7 | 运维/迭代维护 |
| 自定义... | — | 弹出输入框自定义阶段名称 |

**交互**:
- 点击 = 展开下拉列表
- 选择阶段 = 更新 `overview.phase`，同步写入 `project_overview.md`
- 选择"自定义" = 弹出小输入框，输入后保存

**数据来源**: `overview.phase`（已有 state，增强编辑功能）

---

### 2.4 ④ 🚀驾驶舱快捷面板

**功能**: 点击展开快捷操作面板，提供常用操作的一键入口

**面板位置**: 绝对定位，在"驾驶舱"按钮下方，宽度 240px

**面板内容**（8 个固定操作，分 3 组）:

```
┌──────────────────────────┐
│  会话操作                 │
│  ┌────────────────────┐  │
│  │ 🆕 新建会话         │  │
│  │ 📋 分支管理 (3)     │  │
│  └────────────────────┘  │
│  系统操作                 │
│  ┌────────────────────┐  │
│  │ 🧹 清除缓存         │  │
│  │ 🔄 重启 Harness     │  │
│  │ 📚 刷新文档索引     │  │
│  └────────────────────┘  │
│  数据操作                 │
│  ┌────────────────────┐  │
│  │ 📤 导出对话         │  │
│  │ 📥 导入对话         │  │
│  └────────────────────┘  │
└──────────────────────────┘
```

| 操作 | 功能 | 实现方式 |
|------|------|---------|
| 🆕 新建会话 | 清空当前对话，开始新会话 | `store.reset()` + 保存 |
| 📋 分支管理 | 打开分支列表面板（切换/删除/重命名） | 新增分支管理弹窗 |
| 🧹 清除缓存 | 清除 Harness 缓存目录（Cache/Code Cache 等） | 调用 Node.js fs 删除 |
| 🔄 重启 Harness | 提示用户完全退出后重启（不自动杀进程） | 显示确认提示 |
| 📚 刷新文档索引 | 重新扫描 docs/ 目录生成索引 | 调用索引生成函数 |
| 📤 导出对话 | 导出当前对话历史为 JSON | 已有 `exportHistory()` |
| 📥 导入对话 | 导入 JSON 对话历史 | 已有 `importHistory()` |

**交互**:
- 点击"驾驶舱" = 展开/收起面板（toggle）
- 点击面板外区域 = 自动收起
- 点击操作项 = 执行对应操作，面板自动收起

### 2.5 ⑥ 版本号

**功能**: 显示当前构建版本号，只读

**格式**: `b{MMDD}-{HHmm}`，来自 `DSH_DOCS_INDEX.generatedAt`

**示例**: `b0902-1033`（9月2日 10:33 生成的文档索引）

**交互**: 悬停显示 tooltip："文档索引生成时间：2026-09-02 10:33"

### 2.6 ⑦ ⚙️设置弹窗（4 tab）

**功能**: 整合原 C 区所有设置项，分 4 个 tab 管理

**弹窗规格**:
- 位置：绝对定位，右上角（⚙️按钮下方）
- 尺寸：宽 360px，高 420px
- 结构：顶部 tab 栏 + 内容区 + 底部操作栏

#### Tab 1: 通用设置

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 自动转发 | 开关 | 关闭 | 开启后总监整理后自动转发到对话，关闭则需手动确认 |
| 外观主题色 | 色板选择 | #4d6bfe | 主强调色，4 个预设色 |
| 记忆高亮色 | 色板选择 | #a78bfa | 记忆面板高亮色，3 个预设色 |
| 布局密度 | 单选 | 标准 | 紧凑/标准，影响间距和字号 |
| 总监 tab 默认视图 | 下拉 | 驾驶舱 | 打开总监 tab 时默认显示的视图 |

#### Tab 2: 模型设置

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 启用本地模型 | 开关 | 开启 | Ollama 本地模型总开关 |
| API Endpoint | 文本输入 | http://localhost:11434 | Ollama 服务地址 |
| 模型选择 | 下拉（可刷新） | qwen2:7b | 从 Ollama /api/tags 获取已安装模型列表 |
| Temperature | 滑块 0-2 | 0.7 | 生成随机性 |
| 最大生成长度 | 数字输入 | 2048 | 单次生成最大 token 数 |
| 连接状态 | 只读显示 | — | 显示 Ollama 连接状态（已连接/未连接+原因） |
| 测试连接 | 按钮 | — | 点击测试 Ollama 连接并显示延迟 |

#### Tab 3: 执行逻辑

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 语言规范整理 | 开关+编辑 | 开启 | 开启后总监自动整理用户输入语言 |
| 上下文记忆 | 开关+编辑 | 开启 | 开启后总监自动关联历史对话上下文 |
| 执行逻辑分析 | 开关+编辑 | 开启 | 开启后总监给出执行建议和分步方案 |
| 对话返回审核 | 开关+编辑 | 开启 | 开启后总监审核模型返回内容质量 |

每个职责的"编辑"按钮 = 打开规则编辑弹窗（大文本框，编辑该职责的 system prompt 规则）

#### Tab 4: 数据管理

| 设置项 | 类型 | 说明 |
|--------|------|------|
| 导出对话历史 | 按钮 | 导出当前项目所有对话为 JSON |
| 导入对话历史 | 按钮+文件选择 | 从 JSON 文件导入对话历史（追加模式） |
| 导出全部配置 | 按钮 | 导出智能体/技能/执行逻辑/项目总览配置 |
| 清除缓存 | 按钮 | 清除 Harness 缓存目录（需确认） |
| 重置总监数据 | 按钮（红色） | 清除所有总监对话历史和配置，恢复默认（需二次确认） |
| 存储状态 | 只读 | 显示 localStorage/IndexedDB/文件存储的使用情况 |

**底部操作栏**:
- 左侧："恢复默认设置"按钮
- 右侧："完成"按钮（关闭弹窗）

### 2.7 折叠功能（A区可折叠收起）

**功能**: A区导航栏可折叠收起，最大化内容区域空间。与B区、D区折叠功能统一风格。

**折叠状态**:
- 展开时：高度 40px，显示完整导航栏（7个元素）
- 折叠时：高度 24px，只显示极简条

**折叠后显示内容**（从左到右）:
```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 🎯 总监                                    展开 ▲                            │
└─────────────────────────────────────────────────────────────────────────────┘
```
- 左侧：🎯 图标 + "总监"文字（12px）+ 状态指示点（4px）
- 右侧："展开 ▲" 按钮（10px，点击恢复完整导航栏）
- 折叠时项目名/阶段/驾驶舱/版本号/设置全部隐藏

**交互**:
- 点击折叠按钮（展开状态下导航栏最右侧的"▼"小按钮）= 折叠收起
- 点击折叠状态下的"展开 ▲"按钮 = 恢复展开
- 双击导航栏空白区域 = 切换折叠/展开（快捷操作）
- 折叠状态持久化到 localStorage（`dsh.director.nav.collapsed`）
- 默认状态：展开（false）

**与B区/D区折叠的联动**:
- 三个区域独立折叠，互不影响
- 可同时折叠A+B+D，只留消息区最大化
- 折叠状态各自持久化

## 四、交互流程

### 4.1 项目切换流程
```
点击项目选择 → 展开下拉列表 → 选择项目 →
  1. 保存当前项目对话历史
  2. 加载新项目数据（对话/总览/任务/配置）
  3. 更新 currentProject state
  4. 显示 toast 提示
  5. 下拉列表自动收起
```

### 4.2 阶段编辑流程
```
点击阶段标签 → 展开下拉列表 →
  选择预设阶段 → 更新 overview.phase → 同步写入文档 → 收起
  选择"自定义" → 弹出输入框 → 输入名称 → 保存 → 收起
```

### 4.3 设置弹窗流程
```
点击 ⚙️ → 展开弹窗（默认 tab=通用） →
  切换 tab → 显示对应设置内容 →
  修改设置 → 实时保存到 state.config →
  点击"完成"或弹窗外部 → 收起弹窗
```
