# D 区 · 统一功能面板详细设计文档

> **版本**: V10-design-v1.0
> **日期**: 2026-09-02
> **区域定位**: 总监页面 B 区下方的核心功能区，统一管理智能体/技能/执行逻辑三类资源
> **核心创新**: 左侧导航三态切换 + 右侧统一列表（搜索/筛选/新建/查看/编辑/调用）

---

## 一、区域概述

D 区是总监页面的核心功能区，将原 V9 的"智能体栏/技能栏/执行逻辑栏"三行平铺，重构为"左侧导航 + 右侧内容"的两栏布局。左侧 100px 导航切换智能体/技能/执行逻辑，右侧显示对应资源的列表（含搜索、筛选、新建、查看、编辑、调用）。

### 布局结构

```
┌──────────┬──────────────────────────────────────────────────────────────┐
│          │  🔍 搜索...  [全部▾] [已启用▾]                    [+ 新建]  │ ← 工具栏
│  🤖 智能体 │ ┌──────────────────────────────────────────────────────────┐ │
│     (5)  │ │ 💻 代码工程师    资深全栈开发...    [查看][编辑][调用 →] │ │
│  ⚡ 技能  │ ├──────────────────────────────────────────────────────────┤ │
│     (6)  │ │ 📄 文档专家      技术文档撰写...    [查看][编辑][调用 →] │ │ ← 列表
│  📋 执行  │ ├──────────────────────────────────────────────────────────┤ │
│     逻辑  │ │ 🔍 调研分析师    深度调研...        [查看][编辑][调用 →] │ │
│    (4)   │ └──────────────────────────────────────────────────────────┘ │
└──────────┴──────────────────────────────────────────────────────────────┘
  左侧导航                          右侧内容区
  (100px 固定)
```

### 尺寸规格
- 左侧导航：宽 100px，高度自适应（最小 180px）
- 右侧内容区：flex:1，包含工具栏（40px）+ 列表（自适应高度，可滚动）
- 列表项：高 56px，间距 6px
- 整个 D 区：最小高度 200px，随内容增长

## 二、左侧导航设计

### 2.1 导航项

| 导航项 | 图标 | 数量徽标 | 说明 |
|--------|------|---------|------|
| 智能体 | 🤖 | (5) | AI 角色，调用=创建新分支 |
| 技能 | ⚡ | (6) | 处理工具，调用=注入 prompt |
| 执行逻辑 | 📋 | (4) | 全局规则，调用=强制生效 |

### 2.2 导航交互
- 点击导航项 = 切换右侧内容区显示对应资源列表
- 当前激活项：白色背景 + 左侧 3px 蓝色边框 + 蓝色文字 + 加粗
- 非激活项：灰色背景 + 灰色文字，悬停时浅灰背景
- 数量徽标：导航项文字右侧，小字灰色，显示该类资源的总数
- 切换时保持各自的搜索/筛选/滚动状态（不重置）

### 2.3 State
- `dNavTab`: string — 当前导航 tab（agent / skill / logic）
- `dSearch`: object — 每个 tab 的独立搜索词（{agent:"", skill:"", logic:""}）
- `dFilter`: object — 每个 tab 的独立筛选条件（{agent:{type:"all",status:"all"}, ...}）
- 滚动位置：用 ref 保存每个 tab 的滚动位置，切换时恢复

## 三、工具栏设计

### 3.1 工具栏元素（从左到右）

| 元素 | 宽度 | 说明 |
|------|------|------|
| 搜索框 | 200px | 按名称/描述/触发词搜索，实时过滤 |
| 类型筛选 | 自适应 | 下拉：全部/按分类（智能体：开发类/文档类/分析类；技能：代码类/文档类/通用类；执行逻辑：输入处理/输出规范/质量控制） |
| 状态筛选 | 自适应 | 下拉：全部/已启用/已禁用 |
| 弹性空白 | flex:1 | 左右分隔 |
| 新建按钮 | 自适应 | "+ 新建"，点击打开新建表单弹窗 |

### 3.2 搜索逻辑
- 实时搜索（输入后 300ms 防抖）
- 搜索范围：名称 + 描述 + 触发词（技能）+ system prompt 摘要
- 不区分大小写
- 搜索结果高亮匹配文字

### 3.3 新建按钮
- 点击 = 打开新建表单弹窗（根据当前 tab 类型显示不同表单）
- 智能体新建：名称/图标/描述/system prompt
- 技能新建：名称/图标/触发词/描述/prompt
- 执行逻辑新建：名称/描述/规则内容/触发方式

## 八、三类资源的核心区别

| 维度 | 智能体 | 技能 | 执行逻辑 |
|------|--------|------|---------|
| **本质** | AI 角色 | 处理工具 | 全局规则 |
| **调用行为** | 创建新分支（新对话） | 注入 prompt 到当前对话 | 强制下一次回复遵循规则 |
| **持续时间** | 分支生命周期内持续 | 一次性处理 | 全局持续 / 一次性 |
| **数据存储** | agents.json | skills.json | duties.json + state.config.duties |
| **数量** | 5 个预设 + 可新建 | 6 个预设 + 可新建 | 4 个预设 + 可新建 |
| **查看弹窗** | system prompt | skill prompt | 规则内容 |
| **调用按钮文字** | 调用 → | 调用 → | 强制执行 |
| **与分支关系** | 每个智能体对应一个分支 | 无分支概念 | 无分支概念 |

## 九、数据持久化

### 9.1 存储位置优先级
1. **项目文件**（优先）：`config/agents.json`、`config/skills.json`、`config/duties.json`
   - 通过 Node.js fs API 读写（Harness 渲染进程有 nodeIntegration）
   - 数据随项目走，切换项目时自动切换
2. **localStorage**（回退）：`dsh.director.agents`、`dsh.director.skills`
   - 当文件读写失败时使用
   - 数据不随项目走

### 9.2 加载时机
- DirectorView 挂载时，并行加载 agents/skills/duties 三类数据
- 切换项目时，重新加载对应项目的配置
- 编辑/新建/删除后，立即写入文件并刷新 state

## 十一、边界情况处理

### 11.1 列表为空

当某类资源（智能体/技能/执行逻辑）数量为0时，右侧内容区显示空状态提示：

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│                    📭 暂无智能体                             │
│              点击右上角"+ 新建"创建第一个智能体              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- 图标：对应类型的emoji（🤖/⚡/📋）
- 文字："暂无{类型名称}" + 引导文字
- 不显示搜索框和筛选（或显示但禁用）

### 11.2 搜索无结果

当搜索关键词没有匹配项时，列表区显示：

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│                    🔍 未找到匹配项                           │
│              尝试其他关键词，或清除搜索条件                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- 显示当前搜索关键词
- 提供"清除搜索"按钮（一键清空搜索框）

### 11.3 删除确认

删除智能体/技能/执行逻辑时，必须二次确认：

1. 点击列表项的"删除"按钮（编辑弹窗内）
2. 弹出确认对话框："确定要删除【{名称}】吗？此操作不可撤销。"
3. 按钮：[取消] [确认删除]（红色）
4. 确认后：从数据文件删除 → 更新state → 关闭弹窗 → toast"已删除：{名称}"

**特殊情况**：
- 删除智能体时，如果该智能体有活跃分支，提示："该智能体有 {N} 个活跃分支，删除后分支将保留但无法再调用该智能体。"
- 删除技能时，如果该技能的触发词正在被使用，无影响（删除后触发词不再匹配）

### 11.4 新建时重名处理

新建智能体/技能/执行逻辑时，如果名称已存在：

1. 点击"创建"时检查名称唯一性
2. 如果重名：在名称输入框下方显示红色提示"该名称已存在，请使用其他名称"
3. 不关闭弹窗，不创建，允许用户修改名称
4. **id 唯一性**：id 由名称转小写+时间戳生成，即使名称相同id也不同，但仍建议名称唯一

### 11.5 技能触发词冲突

新建/编辑技能时，如果触发词已被其他技能使用：

1. 点击"保存/创建"时检查触发词唯一性
2. 如果冲突：在触发词输入框下方显示红色提示"触发词 /{trigger} 已被【{已有技能名}】使用，请修改"
3. 不关闭弹窗，不保存，允许用户修改触发词
4. **触发词格式校验**：必须以 / 开头，只包含字母、数字、连字符（/^\/[a-zA-Z0-9-]+$/）

## 十二、折叠功能（D区可折叠收起）

**功能**: D区统一功能面板可折叠收起，与A区、B区折叠功能统一风格。折叠后只显示header条，最大化消息区空间。

**折叠状态**:
- 展开时：显示完整两栏布局（左侧导航100px + 右侧内容区），最小高度200px
- 折叠时：只显示header条（高度28px）

**折叠后header条**（从左到右）:
```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ▶ 智能体(5) · 技能(6) · 执行逻辑(4)                                        │
└─────────────────────────────────────────────────────────────────────────────┘
```
- 左侧："▶" 折叠箭头 + 标题文字（显示三类资源的数量汇总）
- 标题格式："智能体({N}) · 技能({N}) · 执行逻辑({N})"
- 右侧：无按钮（整个header条可点击展开）

**交互**:
- 展开状态下：点击header条左侧的"▼"箭头 = 折叠收起
- 折叠状态下：点击整个header条 = 展开
- 折叠状态持久化到 localStorage（`dsh.director.dPanel.collapsed`）
- 默认状态：展开（false）

**与A区/B区折叠的联动**:
- 三个区域独立折叠，互不影响
- 可同时折叠A+B+D，只留消息区最大化
- 折叠状态各自持久化
- 折叠时不影响数据加载和后台逻辑（智能体/技能/执行逻辑仍可通过其他方式调用）

**折叠时的功能可用性**:
- 折叠后D区功能不可直接点击，但：
  - 技能触发词（/code等）仍可在输入框使用
  - 执行逻辑全局规则仍自动生效
  - 智能体可通过驾驶舱面板的分支管理切换
