## 五、风险点和注意事项

### 5.1 高风险点
| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| client.js 是编译产物，JSX 都是 react_jsx_runtime.jsx() 调用，新增复杂弹窗代码量大 | 语法错误导致 Harness 白屏 | 每阶段完成后 node --check 验证，apply 前自动快照 |
| D 区三态切换时状态保持 | 切换 tab 后搜索/筛选/滚动重置，用户体验差 | 每个 tab 独立 state（dSearch/dFilter），滚动位置用 ref 保存 |
| 数据文件读写在渲染进程 | fs API 可能不可用，或权限问题 | 优先使用 Harness 提供的 directorFs API，回退到 localStorage |
| 原 AGENT_PROMPTS 常量删除后，其他引用处报错 | 运行时 ReferenceError | 全局搜索 AGENT_PROMPTS，确保所有引用都改为 agents state |

### 5.2 注意事项
1. **不要修改原对话 tab（ChatView）和轨迹 tab 的代码**，只修改 DirectorView 组件
2. **保留原有的 localStorage 持久化逻辑**，文件存储是增强不是替换
3. **每个新增函数都要加 V10 注释标记**，便于后续维护和定位
4. **弹窗组件使用简单的绝对定位 div + 原生 form**，不引入复杂组件库
5. **大文本编辑用 textarea**，不引入代码编辑器
6. **apply.ps1 修改后要测试**，确保 assets.json 生成正确
7. **删除原 C 区状态条时，确保其 state（如 autoForward）迁移到设置弹窗**，不丢失功能
