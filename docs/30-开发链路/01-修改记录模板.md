# 01 - 修改记录模板

> 文档编号：DSH-MOD-CHANGE-01 ｜ 版本：V1.0 ｜ 日期：2026-08-24
> 用途：每次对 workspace/ 中文件的修改都应在此记录，便于追踪和回滚。

## 修改记录格式

每次修改填写以下条目，按时间倒序排列（最新在最前）。

```
### <日期> <简短标题>
- **包名**: <dsh-client-xxx>
- **文件**: <lib/client.js 或相对路径>
- **修改位置**: <行号或函数名/特征字符串>
- **修改内容**: <改了什么，原始 → 修改后>
- **目的**: <为什么改>
- **验证方式**: <如何验证修改生效>
- **状态**: <待应用 / 已应用 / 已回滚>
```

## 修改注意事项

1. **修改前先确认包状态**：运行 `status.ps1`，确保目标包在 workspace/ 中存在
2. **只修改需要改的文件**：不要格式化整个文件，保持最小改动
3. **记录精确位置**：编译后的 `lib/client.js` 通常是单行或几行，记录特征字符串而非行号
4. **修改后运行 diff.ps1**：确认只改了预期的文件
5. **应用前创建快照**：`apply.ps1` 会自动创建，也可手动 `snapshot.ps1 -Label xxx`
6. **应用后完全重启 Harness**：`client.js?rev=` 缓存机制要求完全退出后重启
7. **回滚**：单包回滚用 `restore.ps1 -Package <name>`，全量回滚用 `restore.ps1`
